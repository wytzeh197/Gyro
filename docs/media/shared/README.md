# Shared launch assets

These existing Gyro assets are retained for the launch-film tools after the website moved to the private [gyro-website repository](https://github.com/wytzeh197/gyro-website). Their bytes are unchanged. The film tools reuse the self-hosted Inter and Inter Tight fonts from `apps/desktop/public/fonts/`; their license attribution remains in `packages/ui/src/assets/fonts/ATTRIBUTIONS.md`.

`hero-2400.webp` is a historical product composition with generated coastal surroundings. The product window contains a captured Gyro interface. `gyro-logo.png` is the Gyro brand asset used by the existing film compositions.
