# Gyro v0.1.0-alpha.30.1

Gyro Alpha 30.1 is a correctness release. Chat answers again when Claude Code
streams, Settings stops claiming a provider is connected when every send is
being rejected, and dropdowns close when you click away from them.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.1/Gyro_0.1.0-alpha.30.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.1/Gyro_0.1.0-alpha.30.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.1/SHA256SUMS)

## What changed

- **Chat reads Claude Code's stream again.** Claude Code 2.1.218 moved its
  partial messages inside a `stream_event` envelope. Nothing Gyro parsed matched
  a known shape, so a successful turn was answered with a dump of its own
  transcript. Gyro reads the envelope, and falls back to the completed assistant
  message and the final result line when no deltas arrive.
- A provider run that finishes with nothing readable is now reported as version
  drift, the same way a rejected command-line flag already was, instead of
  surfacing as an opaque failure with a retry hint that could never succeed.
- **Provider health believes sends over status commands.** The provider CLIs
  answer their status commands from stored credentials without checking them, so
  Settings could report a verified sign-in for a token the API had expired weeks
  earlier. A send the provider rejects now records that state and outranks later
  probes until a fresh sign-in repairs it.
- **Dropdowns, popovers, and menus close on a press outside them.** The composer
  pickers, the sidebar chat menu, queued-message options, and the Settings
  provider overflow previously stayed open when you clicked elsewhere — the
  composer's model picker survived a click into the message box, and the
  provider overflow only ever closed from its own button.
- The composer's slash-command menu closes when you click outside the composer,
  and stays open while you keep typing the command.
- The macOS menu bar popover hides when you click away from it, instead of
  floating above other applications until the tray icon was pressed again.
- Tiled chat panes pick up the layout rules the multi-pane grid was missing.

## Behavior changes and known limits

- The stream fix targets Claude Code's current envelope. A provider CLI that
  changes its output shape again will be reported as version drift rather than
  silently mis-rendered, but it will still need a Gyro update to read.
- A provider marked as rejected stays rejected until a sign-in completes. A
  status command alone will not clear it, which is the point — that is the claim
  that proved unreliable.
- Menu dismissal is driven by pointer presses. Keyboard `Esc` handling is
  unchanged where it already existed.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 30 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 30 data remains compatible with Alpha 30.1. Update from Gyro or replace
the existing application with the matching Alpha 30.1 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.30`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.30).

## CLI

The CLI is unchanged in this release and remains version-aligned with the app.
After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.1/gyro-cli-0.1.0-alpha.30.1-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.1/gyro-cli-0.1.0-alpha.30.1-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
