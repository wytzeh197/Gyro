# Gyro v0.1.0-alpha.30.4

Gyro Alpha 30.4 fixes Claude Code context metering that reported turn billing
totals as if they filled the context window — so a short tool-using turn could
read as millions of tokens against a 200K window with nothing remaining. It also
keeps multi-block assistant replies in order with the work between them, and
adds a create-branch action to the composer branch menu.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.4/Gyro_0.1.0-alpha.30.4_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.4/Gyro_0.1.0-alpha.30.4_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.4/SHA256SUMS)

## What changed

- **Claude context usage no longer confuses billing totals with the window.**
  Claude Code's closing frame sums every request in a tool-using turn. Gyro was
  storing that sum as "context used," which read as figures like 4.8M of 200K
  with zero remaining after ordinary work. The meter now prefers per-request
  occupancy, keeps only the model window from the turn close, and drops any
  reading larger than the window — including totals already stored on older
  sessions.
- **Plan limits stay honest while still visible.** Unreported 5-hour and weekly
  windows show as unmeasured rather than inventing a fill, and a reading that
  exceeds the context window never clamps the bar to "full" by mistake.
- **Multi-block assistant replies keep their place.** Text that resumes after
  tools is marked as a new block, so preambles stay next to the work they
  introduced and the closing answer is the last thing in the turn instead of
  one glued bubble.
- **The run clock only moves forward.** Timeline step offsets are clamped so an
  out-of-order first-seen timestamp cannot report an earlier second than the
  step above it.
- **A lone tool step keeps its real label** instead of collapsing to a generic
  "Used tool."
- **Create a branch from the composer.** The branch menu offers **New branch…**
  from the current tip (or a chosen start point), without leaving the chat.

## Behavior changes and known limits

- Metering changes how usage is read and stored; they do not change how Claude
  Code bills Anthropic plan limits. A real 5-hour or weekly limit from Claude
  still appears when Claude reports it.
- Sessions recorded before this fix stop showing inflated context totals in the
  composer; they fall back to a thread estimate until a new turn reports a
  valid per-request reading.
- Segment marks on multi-block assistant messages are stream metadata. Older
  transcripts without those marks still render as a single bubble.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 30.3 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 30.3 data remains compatible with Alpha 30.4. Update from Gyro or replace
the existing application with the matching Alpha 30.4 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.30.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.30.3).

## CLI

The CLI is unchanged in this release and remains version-aligned with the app.
After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.4/gyro-cli-0.1.0-alpha.30.4-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.4/gyro-cli-0.1.0-alpha.30.4-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
