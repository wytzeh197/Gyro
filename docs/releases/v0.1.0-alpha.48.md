# Gyro v0.1.0-alpha.48

Gyro Alpha 48 improves chat reliability, browser activity, and file review.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch
requires Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48/Gyro_0.1.0-alpha.48_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48/Gyro_0.1.0-alpha.48_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Final answers stay after the work that produced them. Reopening chats preserves
  streamed reply placement, and short answers remain visible.
- Saved and live chat events reconcile without removing matching text from other
  turns or sessions.
- Browser activity shows specific actions and the element they touched, with a
  visible model cursor and temporary highlight.
- Closed and background browser panels stay hidden during pending navigation
  and resizing.
- File reads open editor tabs only when Follow model is enabled for the active
  chat. Full Access file edits apply through the guarded write transaction;
  review mode continues to require file review.
- The browser panel, file review, chat tiling, attachments, and composer resizing
  receive interaction and layout fixes.
- Daily usage pace warnings account for elapsed time in the provider's weekly
  allowance and prefer measured plan usage unless a custom token budget is set.
- Session titles appear when the opening text block finishes.

## Behavior changes and known limits

- Gyro Browser remains owned by its chat, and page content is untrusted context.
- Usage warnings depend on provider reporting and reset times; they are not a
  guarantee of remaining allowance.
- Existing file hashes, workspace path limits, and atomic replacement protections
  remain in force for Full Access writes.
- External provider connections, native permissions, and updater installation
  still require desktop acceptance beyond automated regression tests.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.7`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.7).
This release does not introduce a session schema migration; older versions may
render the added reply-placement metadata differently.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48/gyro-cli-0.1.0-alpha.48-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48/gyro-cli-0.1.0-alpha.48-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
