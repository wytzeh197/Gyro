# Gyro v0.1.0-alpha.48.3

Gyro Alpha 48.3 refines chat layout and pacing: activity stays inside the
chat pane, the transcript has more room above the composer and queue, and
queued messages pause briefly between turns.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.3/Gyro_0.1.0-alpha.48.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.3/Gyro_0.1.0-alpha.48.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.3/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Corrected the native traffic lights' vertical offset to match the sidebar
  navigation controls.
- Removed remaining-context subtitles from model picker rows.
- Constrained activity columns so long commands truncate within the chat pane
  and narration wraps instead of overflowing.
- Added 64px of transcript scroll room and included the entire composer dock,
  including the queue, in bottom clearance.
- Automatic queued delivery pauses for three seconds after a turn completes,
  independently for each chat.
- Process supervision now recognizes explicit servers and watchers, excludes
  finite checks and unknown commands, and hides stale misclassified cards.
- Saved final replies remain visible when late activity sorts after them,
  with regression coverage and a rendered chat replay.

## Behavior changes and known limits

- Final-reply hardening has been verified in a browser replay; the installed
  app needs the updated build for native acceptance.
- Automated checks cover layout contracts and queue scheduling. Native visual
  acceptance and in-app upgrade behavior still require desktop verification.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.3 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.2).
This release does not introduce a session schema migration; older versions do
not include these chat layout and queue pacing fixes.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.3/gyro-cli-0.1.0-alpha.48.3-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.3/gyro-cli-0.1.0-alpha.48.3-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
