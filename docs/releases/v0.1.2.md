# Gyro v0.1.2

Gyro 0.1.2 adds local project memory, second-opinion code reviews, and reusable
workflows. Browser annotations connect a selected page element and screenshot to
your chat. This release also improves Git readiness, queued messages, provider
recovery, and the chat and workflow interfaces.

## What changed

- Project memory stores reusable project context locally, with explicit editing,
  forgetting, and suggestion review. Relevant entries use a bounded context budget;
  unchanged acknowledged memory is not repeated on resumed conversations.
- Second-opinion reviews capture a fixed change set and return findings tied to
  that snapshot. Review selected findings, request fixes, and re-review the result.
- Reusable workflows combine configured agent, review, and verification steps.
  Inspect setup, schedules, run results, and interrupted work from Workflows.
- Browser annotations let you select a visible element, add a comment beside its
  capture, and send the cropped image and bounded element context to chat.
- Git readiness distinguishes optional setup from failures, retains clearly marked
  stale results, and reconciles successful retries without hiding other warnings.
- Chat updates refine queued-message controls, questions, tool status, context
  compaction, and provider recovery. Tool-output previews retain paths to fuller
  evidence; these changes do not establish an overall token-saving benchmark.

## Behavior and known limits

Local work and user-owned provider connections remain available without a Gyro
account. Account, Plan & billing, and Cloud remain coming-soon settings; this
release does not enable hosted sign-in, purchases, uploads, sharing, or managed AI.

Second-opinion reviews use supported API or Ollama connections. CLI adapters are
not supported for the advisory review step. Findings are model output and require
inspection; requesting a fix does not itself resolve a finding.

Workflows run in local checkouts or separately opened external worktrees.
Gyro-managed private worktree execution is unavailable. Interrupted steps require
inspection and explicit continuation; uncertain work is not automatically replayed.
Workflow agent steps do not automatically inject project memory.

Browser annotations use element bounds when exact geometry is unsupported.
Canvas internals, closed shadow contents, embedded frames, and form controls are
not individually selectable. Provider support depends on the installed provider,
account, model, and configuration. Cursor and OpenCode remain experimental.
Notebook and binary file edits are refused.

## Upgrade and rollback

Quit Gyro and back up `~/Library/Application Support/Gyro/` before upgrading or
rolling back. Back up project `.gyro/` directories too: project memory and saved
workflow definitions belong to their projects. Install the matching DMG or use
the signed in-app updater. Verify that sessions, provider settings, project
memory, and workflows survive the update before removing backups.

To roll back, quit Gyro and manually reinstall
[v0.1.1](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.1).
The updater does not perform downgrades. Restore the matching backup if the older
build cannot read newer data; cross-version downgrade acceptance has not been
established. When replacing an older ad-hoc build for the first time, grant
Accessibility again if requested; a one-time Keychain prompt may also appear.

## CLI

Keep app and CLI versions aligned when handing sessions between them:

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.2/gyro-cli-0.1.2-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.2/gyro-cli-0.1.2-x86_64-apple-darwin.tar.gz)

Each archive has a `.sha256` sidecar. The release includes the generated `gyro.rb`
Formula. After the validated Formula reaches the tap:

```sh
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only.
