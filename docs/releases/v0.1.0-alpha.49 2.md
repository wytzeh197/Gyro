# Gyro v0.1.0-alpha.49

Gyro Alpha 49 turns Canvas into a place to build and try things rather than read
them. A model can author an interactive UI piece as a Canvas item and you try it
in place: a Preview with responsive widths, a Code editor beside it, and
revisions that land on the same item without throwing away an unsent draft.
Provider setup stops assuming a provider, diff review reads like a diff with
real line numbers and wrapping, change counts no longer invent numbers, and
background Git reads share one deadline instead of each starting a fresh one.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49/Gyro_0.1.0-alpha.49_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49/Gyro_0.1.0-alpha.49_x64.dmg)

## What changed

- **Canvas builds interfaces, not just documents.** A Canvas item can carry
  `format: "html"`: self-contained HTML, styles, and script that renders in a
  Preview with a Code editor one click away. Preview offers Fit panel, 375, 768,
  and 1280 widths plus a Restart control, so a layout can be checked at phone,
  tablet, and desktop size without leaving the chat. Revising an item reuses its
  id, an unsent local draft survives the revision and can be restored with **Use
  model version**, and the edited draft hands back to the composer with **Send
  to chat**. Text and code items stay inert, as before.
- **The preview runs where it cannot reach Gyro.** In a packaged build the
  Canvas runtime is served from its own `gyro-canvas://` origin by a dedicated
  native protocol that answers `GET /` and nothing else, under a policy with no
  same-origin, no `connect-src`, and no frames. The document arrives as one
  message from its parent, and there is deliberately no channel back: the frame
  cannot read the parent DOM, storage, or Tauri internals, and a fetch from
  inside it fails. A headless-browser check exercises interaction, revision,
  draft preservation, responsive sizing, handoff, and those isolation
  boundaries.
- **A new chat asks for a provider instead of picking one.** An unconfigured
  workspace leads to provider settings — an existing account, an API key, or a
  local model — rather than joining a provider implicitly. Connection progress
  stays visible for the whole attempt, a per-provider guard stops a second
  connect from starting while one is in flight, and a provider that reports
  itself usable offers **Use in chat**, which selects its default model for the
  current chat and opens the chat layout.
- **Diff review reads like a diff.** Comparison review shows old and new line
  numbers per line, calls its hunks *changed sections*, and offers a **Wrap
  lines** toggle for long lines. The file list shows each file's name with its
  folder beneath it, and both the list and the diff toolbar carry the file's
  change counts.
- **Counts that were measured stay measured.** An applied mutation receipt now
  supplies its file counts even when its approval row is not rendered, so the
  live, completed, and Review surfaces agree on what the turn wrote. Counts
  survive a reload, an explicitly reported zero replaces an older count, and an
  activity id reused for a different path can no longer transfer counts between
  files. Where no count was ever reported, the badge says **Line counts
  unavailable** instead of showing a zero it did not measure.
- **One chronology for the whole stream.** Provider activity, capability calls,
  and streamed assistant text now share a single order: cumulative commentary
  grows in place instead of repeating, a command keeps the position where it
  started even after it completes, a tool call landing between two tokens of a
  word no longer splits it, and text that resumes after a tool opens a new block
  so a preamble is not glued to the answer. A lost mid-turn sequence frame
  recovers after a handful of later frames instead of stalling until the turn
  ends, and reconciliation with the durable session keeps the order you watched
  arrive.
- **Bounded Git reads share one deadline.** Repository inspection runs through a
  single reader with a wall-clock budget carried across its steps: a read that
  cannot finish answers with the last known changes and says so, rather than
  leaving a stale result that looks current, and a later step cannot start with
  a fresh timeout once the budget is spent. Background status sets
  `GIT_OPTIONAL_LOCKS=0`, so it never refreshes the index or contends with an
  explicit stage or commit; that setting is never applied to a Git mutation.
- **Settings sheds rows that did nothing.** General, Appearance, and Advanced
  lost the fixed rows with no control behind them (startup behavior, default
  workspace, default surface, session restore, continuing sessions from the CLI,
  terminal font, reduce motion, and the local socket row), along with their
  search entries; group spacing was tightened and rounded enclosures gave way to
  thin separators.
- **DeepSeek Flash accepts images.** Image attachments now reach the
  OpenAI-compatible client for the models that support them, sent as `image_url`
  data parts under a MIME allowlist (PNG, JPEG, GIF, WebP). A DeepSeek model
  without image support refuses the turn and names the model to switch to
  rather than failing the request.
- **A prepared workspace is only reused when it was ready.** Cached preparation
  results are replayed only when they finished *ready* with no errors, so a
  workspace that failed to prepare is prepared again instead of being reported
  as done.

## Behavior changes and known limits

- Canvas HTML is generated content and is treated as untrusted: inline styles
  and script and `data:` images only. It cannot fetch the network, start a dev
  server, install packages, or reach Gyro's tools or workspace files. An app
  that needs dependencies or an API still belongs on a loopback dev server.
- The runtime refuses a document larger than 100,000 characters; the documented
  Canvas budget (about 12,000 characters, 16 KiB encoded) is unchanged.
- Canvas previews use the development runtime page under Vite and the dedicated
  `gyro-canvas://` origin in the packaged app. Both run the same isolated
  runtime; only the transport differs.
- An applied-receipt count is a measurement, not a diff: it reflects what a
  guarded mutation reported, and a turn that never reported counts shows no
  numbers rather than an estimate.
- A Git inspection that hits its deadline reports that it is showing the last
  known changes; retry to refresh.
- This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 49 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.9`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.9).
This release adds an optional `html` Canvas item format and no session schema
migration; an older build ignores what it does not recognize, so sessions keep
working in both directions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49/gyro-cli-0.1.0-alpha.49-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49/gyro-cli-0.1.0-alpha.49-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
