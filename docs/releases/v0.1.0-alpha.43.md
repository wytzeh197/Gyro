# Gyro v0.1.0-alpha.43

Gyro Alpha 43 fixes a real multi-chat reliability problem: a turn can now show
only the files it actually changed, even when several chats share one local
workspace. It also tightens the working timeline and split-chat layout.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.43/Gyro_0.1.0-alpha.43_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.43/Gyro_0.1.0-alpha.43_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.43/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **File changes now belong to the correct chat.** Gyro retains the paths from
  the provider's patch rather than assigning the whole shared Git diff to any
  chat that reports a file change. A chat with no reported paths does not claim
  another chat's edits.
- **Working status is easier to read.** Plain-language updates appear as
  narration, adjacent technical actions fold into expandable phases, and the
  active phase names what is happening instead of showing only a generic
  working label.
- **Completed turns keep their conclusion.** The final response remains above
  the edit summary, so a successful change does not hide the assistant's
  outcome.
- **Split chats align correctly.** Empty tiled composers now match the docked
  composer height, and workspace projects use closed/open folder icons in the
  sidebar.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- File attribution is exact for newly reported provider patches. Historical
  pathless activity is intentionally not expanded into the current workspace
  diff, because that would be false attribution.
- A provider chat still requires a configured account or locally installed
  model.

## Upgrade and rollback

Alpha 42 data remains compatible with Alpha 43. Update from Gyro or replace
the application with the matching Alpha 43 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.42`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.42).
Existing local sessions remain available after the rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.43/gyro-cli-0.1.0-alpha.43-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.43/gyro-cli-0.1.0-alpha.43-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
