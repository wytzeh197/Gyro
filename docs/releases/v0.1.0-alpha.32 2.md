# Gyro v0.1.0-alpha.32

Gyro Alpha 32 is a Workspace-focused release. Source Control can select and
create branches and commit work like a normal editor SCM panel, Browser enters a
preview-first layout when it is active, and the clean-machine path from open
project to connected provider is clearer. Model Council remains built but frozen
as coming soon.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.32/Gyro_0.1.0-alpha.32_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.32/Gyro_0.1.0-alpha.32_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.32/SHA256SUMS)

## What changed

- **Source Control branch picker.** Choose a local branch from the SCM panel or
  the Workspace status bar, create a new branch, and refresh status and branch
  lists together. The old static “No branch” chip is gone.
- **Commit work from Source Control.** Stage all, stage or discard selected
  files, and commit. When nothing is staged, **Commit all** stages remaining
  changes then commits (VS Code-style). Ctrl/Cmd+Enter submits from the message
  field. Errors from Git surface in the panel instead of a vague “not ready”.
- **Compact SCM layout.** Section headers no longer collide (the Actions
  overlap is fixed). Repository, Changes, and GitHub runs are denser and quieter.
- **Browser focus mode.** Selecting the Browser tool tab expands the bottom
  panel, compresses an empty editor, and de-emphasizes file-only AI actions so
  the preview owns the canvas. Desktop previews fill the panel; tablet and
  mobile stay framed.
- **Honest browser status.** Status reads Live, Loading, Ready, or Unreachable
  instead of claiming “No preview loaded” while a localhost URL is set.
- **Workspace sidebar stays open.** In Workspace (code layout) the sidebar
  cannot be hidden, so hide-without-unhide no longer strands the explorer.
- **Clean-machine path.** Empty Chat shows a project → provider → send
  checklist with real next actions. Disconnected providers offer Connect in
  the model picker instead of dead Unavailable rows. Automated checks cover the
  path state machine (`docs/clean-machine-path.md`).
- **Model Council freeze.** Council remains in the tree but is frozen as
  coming soon so it cannot start a run until unfrozen.

## Behavior changes and known limits

- Workspace code layout always shows the explorer/SCM sidebar; Sessions can
  still hide and restore the chat sidebar.
- Branch switch and create require a trusted workspace and a real Git
  repository. Detached HEAD and non-repo folders report that state honestly.
- Commit all stages every unstaged file before committing; review the change
  list first if you only want a subset staged.
- Browser full-bleed shows the live page content; a narrow white column on a
  dark page can be the site itself, not panel letterboxing.
- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 31 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 31 data remains compatible with Alpha 32. Update from Gyro or replace the
existing application with the matching Alpha 32 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.31`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.31).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.32/gyro-cli-0.1.0-alpha.32-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.32/gyro-cli-0.1.0-alpha.32-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
