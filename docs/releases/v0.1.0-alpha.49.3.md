# Gyro v0.1.0-alpha.49.3

Gyro Alpha 49.3 puts the session goal on the composer, rebuilds Settings →
Updates on the same tokens as the rest of Settings, and checks the remote model
catalog on a minute cadence. It includes no session database migration.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.3/Gyro_0.1.0-alpha.49.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.3/Gyro_0.1.0-alpha.49.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.3/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **The goal rides on the composer.** The outcome is one line attached to the
  composer — mark, "Pursuing goal", the outcome, an elapsed clock, and the edit,
  complete/reopen and clear controls — instead of a card at the top of the
  transcript that scrolled out of sight within one reply. Saving no longer
  prints a "Goal saved…" paragraph: the strip itself is the confirmation.
- **The mark turns only while a turn runs.** An open goal that is idle keeps its
  mark still and its clock running.
- **Failing terminal output attaches to chat.** Send the selected output of a
  terminal pane, or the output of a failed task, and the attachment keeps every
  error region plus the end of the run and rewrites absolute file references as
  workspace-relative ones. The transcript offers **Re-run** for the same command
  once the fix lands, and the composer marks the attachment out of date when the
  terminal has moved on.
- **Settings → Updates answers one question.** A single status card built from
  the tokens the rest of Settings already uses: the status dot is the same
  primitive provider rows use, the primary action follows Appearance → Colors,
  and the facts row shows only what the updater actually reported — installed
  version, latest version, download size and last completed check. A restart
  waiting to happen marks the Updates row in the sidebar and says so to screen
  readers.
- **New models arrive sooner.** A focused Gyro checks the remote model catalog
  once a minute and a background one every six hours; both check immediately
  when the window regains focus or the machine comes back online, and they keep
  their last valid catalog while offline. An addition raises a provider
  notification naming the new models. The current catalog adds **Claude Opus
  5.5** (1M context window, reasoning from low to max).

## Behavior changes and known limits

- The goal is no longer repeated above the transcript. The thread keeps the
  plan's step count and **Open plan**; the rail keeps the editable goal.
- Closing the goal editor from the composer chip keeps the draft you were
  writing, and that chip no longer raises a hover tooltip nobody asked for.
- The minute-level catalog cadence ships in this app version: installs on
  earlier Alphas keep the six-hour check until they update.
- Remote additions still need an app build that understands them, and a model
  that needs new native handling still needs a normal app release.
- Model Council remains unavailable while it is frozen.
- This Alpha is ad-hoc signed and is not Apple-signed or notarized.
- Use matching app and CLI versions for session handoff.

## Upgrade and rollback

Update from Gyro, or replace the application with the matching Alpha 49.3 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.2).
This release does not add a session database schema migration. Keep the backup
until you have verified your sessions in the version you intend to use.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.3/gyro-cli-0.1.0-alpha.49.3-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.3/gyro-cli-0.1.0-alpha.49.3-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
