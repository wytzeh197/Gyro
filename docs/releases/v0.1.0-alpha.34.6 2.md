# Gyro v0.1.0-alpha.34.6

Gyro Alpha 34.6 keeps chat turns live until the provider process is actually
done, stops the rail freezing mid-stream, and ships plan/goal and workbench
polish that landed with this release.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.6/Gyro_0.1.0-alpha.34.6_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.6/Gyro_0.1.0-alpha.34.6_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.6/SHA256SUMS)

## What changed

- **Chat stays live while the backend works.** Streaming turns no longer freeze
  the rail when React defers updates, stream flushes are no longer deprioritized,
  and a missing mid-turn stream frame recovers after a handful of later events
  instead of waiting for the end of the turn.
- **Backend reliability.** Live runs emit quiet-period heartbeats so the idle
  watchdog does not settle early; stdout is fully drained before completion;
  stream sequence numbers never collapse to zeros; a non-zero CLI exit still
  completes the turn when a real answer already streamed.
- **Turn status from the backend.** Workbench active-turn liveness prefers
  provider status (and heartbeat timestamps) over “the last bubble looked done.”
- **Plan and goal continuity.** Normal turns can advance checklist steps with
  `update-items`; models can mark an active goal complete; met goals stay in
  context; plan content alone can unlock plan approval.
- **Workbench polish.** Background model-driven file opens no longer steal the
  editor tab; chat-grid drops land in the intended quadrant; explorer/source
  control share file badges; plan decision card polish.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34.x sessions remain compatible.
- Heartbeats cover streaming provider CLIs and Codex app-server; ACP-only
  providers (for example some Kimi/Grok paths) still rely on their own activity
  frames for quiet stretches.
- Partial-success recovery keeps a streamed answer after a non-zero exit; cancel
  and inactivity timeouts still fail closed.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 34.6 DMG.
To roll back, reinstall
[`v0.1.0-alpha.34.5`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.5).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.6/gyro-cli-0.1.0-alpha.34.6-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.6/gyro-cli-0.1.0-alpha.34.6-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
