# Gyro v0.1.6

Ask a second model to review your agent's changes. Choose the reviewer when you
send the task, read the findings when the work finishes, and bring suggested
fixes back to the same chat.

## What changed

- Add a reviewer to a workspace task with `/second-opinion`. The review
  explains its findings, links to the relevant code or captured diff, and can
  prepare a follow-up in the original chat for you to edit and send.
- Resume eligible interrupted Codex turns from the chat. When the provider
  offers model capacity information, Gyro can show it alongside recovery.
- Open **Check this work** from **Changes** after a turn to verify the current
  workspace against requirements you define.
- See upcoming schedules and recent runs in Workflows. The first-run tour now
  walks through a coding task, from choosing a folder to reviewing the result.
- Choose a default model for each connected provider in **Settings → Models &
  accounts**.
- Previously saved global Full access settings reset to **Ask for approval**
  on upgrade. You can grant Full access to a specific local chat through the
  app's confirmation dialog. The grant expires when you quit Gyro.

## Download and install

Requires macOS 14+ on Apple Silicon or Intel. Stable app bundles and DMGs must
be signed with Gyro's Developer ID and notarized by Apple before publication.

- [Download site](https://usegyro.io/)
- [Apple Silicon: Gyro_0.1.6_aarch64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.6/Gyro_0.1.6_aarch64.dmg)
- [Intel: Gyro_0.1.6_x64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.6/Gyro_0.1.6_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.6/SHA256SUMS)

Match the checksum to the exact filename. See the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
If this is your first upgrade from an ad-hoc build to a Developer ID build,
macOS may ask again for Accessibility access and display a one-time Keychain
prompt.

## Behavior and known limits

Second opinions require a local project session and an eligible reviewer
connection. A review may cover only part of the change. Review and resume
availability depend on the connection and run state. Remote Access remains
experimental and requires compatible builds on both Macs. Local work and
user-owned provider connections are available without a Gyro account. Hosted
sign-in, purchases, uploads, sharing and managed AI remain disabled in the
default build.

## Upgrade and rollback

Quit Gyro and back up `~/Library/Application Support/Gyro/` and each project's
`.gyro/` directory. After publication, upgrade through the signed updater or
install the DMG for your Mac. Verify that sessions, provider access, drafts,
project memory and workflows are present before removing the backup.

For rollback, quit Gyro and reinstall
[v0.1.5](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.5). The updater
does not downgrade. Keep the matching data backup for rollback because the
older app may be unable to read data written by the newer version.

## CLI

Use the same CLI and desktop version when handing sessions between them.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.6/gyro-cli-0.1.6-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.6/gyro-cli-0.1.6-x86_64-apple-darwin.tar.gz)

Verify the archive against its `.sha256` sidecar. Homebrew installs the CLI.
After the versioned Formula has reached the tap, run:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```
