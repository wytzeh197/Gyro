# Gyro v0.1.0-alpha.47.5

Gyro Alpha 47.5 keeps workspace preparation on-screen and makes Git status
cheap enough that opening a project no longer sits on Inspecting Git.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.5/Gyro_0.1.0-alpha.47.5_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.5/Gyro_0.1.0-alpha.47.5_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.5/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Workspace preparation details stay inside the window when opened from the
  sidebar footer, instead of clipping off the left edge.
- Opening a project no longer blocks on a full Git inspect. Preparation uses a
  short status, gives Git eight seconds, and continues if inspect times out.
- Source Control no longer runs a full `git status` every 800ms during file
  edits. Event-watched workspaces refresh from the file watcher; polling
  workspaces refresh at 2.5s.
- Git decorations are reused until porcelain or dirty-file fingerprints change.
  Untracked line counts skip files larger than 1MB or past 64 files in one
  refresh and mark the result partial.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Line counts, history, and compared-to-main stats can land after the file list.
  Oversized or numerous untracked files show as partial instead of blocking
  status.
- Source Control still polls every 5 seconds while that panel is visible, so
  edits made outside Gyro continue to appear.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.5 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.4`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.4).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for

and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.5/gyro-cli-0.1.0-alpha.47.5-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
