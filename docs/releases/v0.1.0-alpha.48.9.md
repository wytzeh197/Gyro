# Gyro v0.1.0-alpha.48.9

Gyro Alpha 48.9 makes the transcript's structure trustworthy. A provider
timeline records when each piece of a turn actually arrived, so a command that
finishes late updates the item it belongs to instead of appearing at the bottom
of the conversation. A chat that needs a decision can now ask with a real choice
popup instead of a wall of prose. The browser preview follows its pane when CSS
moves it, and repository status stops showing results from a workspace you
already left.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.9/Gyro_0.1.0-alpha.48.9_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.9/Gyro_0.1.0-alpha.48.9_x64.dmg)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **One chronology for every turn.** Provider frames and broker calls now carry
  a timeline position independent of the streaming delivery counter. A long
  command that reports back late updates the item it belongs to rather than
  inserting itself as new work at the end of the transcript, and a stream flush
  is treated as a transport boundary rather than the start of a new block.
- **Chats can ask with real choices.** When a model ends its turn with explicit
  choice questions, Gyro promotes them into a question popup above the composer
  instead of leaving them buried in prose. Options are parsed only from
  question and list structure, with code fences excluded, so a code sample or an
  ordinary paragraph never becomes a button.
- **The browser preview tracks its host.** The native child webview is now kept
  aligned to the host element's actual on-screen rectangle, so pane swaps,
  sidebar transitions, and CSS transforms no longer leave the preview behind.
  Reads are still throttled to animation frames and reported over IPC only when
  the rectangle changes.
- **Repository status stops lying after a workspace switch.** GitHub reads run
  through a refresh controller that invalidates outstanding reads when the
  workspace changes, so results from a previous workspace cannot land in the
  current one. Mutations are never retried by the controller.
- **Configurable tool-round budget.** `usageGuard.maxToolRounds` sets how many
  tool rounds a single turn may use: the default stays 512, and `0` removes the
  round budget so a long edit sweep runs until the model stops or you do. The
  window and per-call token ceilings still apply, which is what makes `0` safe
  to offer.
- **Documentation and site copy.** `docs/command-waiting.md` and
  `docs/usage-safety.md` describe the round budget and why a long wait belongs in
  one call, and the download site copy and styles were refreshed alongside them.

## Behavior changes and known limits

- A turn that exhausts its tool-round budget stops asking for tools and reports
  a checkpoint instead. Raising `usageGuard.maxToolRounds`, or setting it to
  `0`, is the supported way to let a long sweep continue.
- The question popup is derived from the last assistant message and disappears
  once you reply. A question with fewer than two or more than eight options is
  left as plain transcript text.
- The browser preview rectangle is reported from the main thread each frame; a
  host element smaller than 2×2 pixels is treated as hidden and unregisters the
  child view.
- This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.9 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.8`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.8).
This release does not introduce a session schema migration; an older build
ignores capability and timeline fields it does not recognize.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.9/gyro-cli-0.1.0-alpha.48.9-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.9/gyro-cli-0.1.0-alpha.48.9-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
