# Gyro v0.1.0-alpha.37

Gyro Alpha 37 asks for the macOS folder permissions it needs on first launch
instead of failing silently later, and clears standing furniture out of chat:
the right side panel is opt-in again, and the composer's workspace row and
spend readouts no longer sit under every message.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.37/Gyro_0.1.0-alpha.37_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.37/Gyro_0.1.0-alpha.37_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.37/SHA256SUMS)

## What changed

- **Gyro asks for macOS folder access on first launch.** The app now ships the
  usage descriptions macOS requires for Desktop, Documents, Downloads, and
  removable, network, and cloud-synced volumes, and reads those locations once
  at startup so the system permission sheets actually appear. Opening a project
  from one of those folders previously failed with a permission error and no
  way to recover.
- **Settings shows every macOS grant.** A new **macOS system access** group
  lists each scope with its current state — Allowed, Blocked, or Not on this
  Mac — the reason Gyro wants it, a re-check action, and a button that opens
  the exact System Settings pane that owns the grant. Full Disk Access can
  never be prompted for by any app, so it always routes to System Settings.
- **The chat's right side panel is opt-in.** Chat opens without the rail, and
  the panel button in the chat topbar opens and closes it. It was previously
  pinned open with no way to dismiss it, and its close control did nothing.
- **The composer's workspace row is a start-screen control.** Project, mode,
  and branch chips appear when starting a chat, where they are a choice, and
  stay out of the composer once the chat is running.
- **Spend readouts are out of the composer.** The running token and call
  estimate under the composer is gone, as is the confirmation banner that armed
  an expensive send and required a second press.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 36 sessions remain compatible; no destructive data migration
  is required.
- macOS asks for each folder once. If a prompt was denied, macOS will not ask
  again — use the button in Settings to open System Settings and grant it
  there, then re-check.
- Access states are read at launch and on demand. A grant changed in System
  Settings while Gyro is running shows up after **Re-check access**.
- Removing the pre-send confirmation means an expensive send now goes on the
  first press. Provider budgets and the pause behavior in Settings are
  unchanged and still stop runs.

## Upgrade and rollback

Alpha 36 data remains compatible with Alpha 37. Update from Gyro or replace
the application with the matching Alpha 37 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.36`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.36).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.37/gyro-cli-0.1.0-alpha.37-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.37/gyro-cli-0.1.0-alpha.37-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
