# Gyro v0.1.0-alpha.47.2

Gyro Alpha 47.2 improves browser reliability and workspace usability.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.2/Gyro_0.1.0-alpha.47.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.2/Gyro_0.1.0-alpha.47.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.2/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Browser page reads and screenshots no longer depend on page fetch behavior,
  so restrictive page security policies cannot cause false timeouts.
- Browser interactions now preserve element references across repeated reads,
  fire clicks once, reject stale targets, and block credential-field writes.
- Browser tabs show the current page title and a visible close button. Closing
  a tab closes its native page; reopening starts a new tab.
- Workspace context menus now render above composer controls with an opaque,
  readable surface.
- Added an opt-in native browser smoke check covering read, interact, navigate,
  screenshot, diagnostics, and close behavior.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Browser interactions remain subject to Gyro's approval policy.
- Credential-like fields are intentionally not writable by models.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.2 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.1).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.2/gyro-cli-0.1.0-alpha.47.2-aarch64-apple-darwin.tar.gz)
and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.2/gyro-cli-0.1.0-alpha.47.2-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
