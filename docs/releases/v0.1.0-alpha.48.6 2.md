# Gyro v0.1.0-alpha.48.6

Gyro Alpha 48.6 brings Sessions and Workspace navigation into the title bar,
adds provider API-key settings, and makes missing file-change counts explicit.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.6/Gyro_0.1.0-alpha.48.6_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.6/Gyro_0.1.0-alpha.48.6_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.6/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Sessions and Workspace navigation moves into the title bar, with improvements
  to the initial app shell and embedded surface boundaries.
- Provider settings can save and remove supported API keys in macOS Keychain,
  and provider readiness checks recognize configured keys.
- Completed-chat unread indicators stay cleared after the chat is opened.
- Chat change summaries and Review now distinguish missing line counts from
  measured zero. Incomplete totals are marked unavailable rather than borrowing
  unrelated changes from the shared working tree.

## Behavior changes and known limits

- Providers that omit file-change counts still display “Line counts unavailable.”
  This release does not reconstruct measurements missing from earlier events.
- API-key support depends on the selected provider. Provider CLI sign-in remains
  available where supported.
- This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.6 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.5`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.5).
This release does not introduce a session schema migration.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.6/gyro-cli-0.1.0-alpha.48.6-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.6/gyro-cli-0.1.0-alpha.48.6-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
