# Gyro v0.1.0-alpha.34

Gyro Alpha 34 rebuilds the in-chat run timeline as a flat action rail, recovers
stale provider turns after a crash, tracks provider rate limits without the old
per-call ceiling false positives, and tightens browser layout focus and download
site HTTPS policy.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34/Gyro_0.1.0-alpha.34_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34/Gyro_0.1.0-alpha.34_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34/SHA256SUMS)

## What changed

- **Flat run timeline.** The in-chat run UI is a timestamp-free list of beats:
  one row per action with an icon, bright label, muted description, and hairline
  connector — no grouping or summary cards. A typed model keeps the raw event
  material so the renderer no longer pattern-matches finished English into
  generic “Used a tool” labels.
- **File edits stay inline.** File activity remains in the timeline and is
  tallied while the run is still going, instead of being hoisted out before
  render.
- **Stale provider turn recovery.** Turns left at `running` by a crash or
  force-quit are swept at startup so they no longer block retry for the life of
  the session.
- **Provider rate limits.** Gyro records what providers claim about their plan
  windows, surfaces that in the desktop UI, and measures fresh input plus
  output for the per-call ceiling so ordinary tool use no longer trips it within
  minutes.
- **Browser panel focus.** The workspace code route no longer splits into
  editor + empty preview when the browser pane tab is selected but the tool
  panel is closed.
- **Download site HSTS.** usegyro.io sends HSTS (starting at a short max-age)
  so bare HTTP no longer stays on cleartext with a 200.
- **Session browser capability and workbench smoke baseline.** Session browser
  support, provider logo marks, and a recorded workbench smoke baseline in CI
  ship with this release.

## Behavior changes and known limits

- The previous run timeline shape (grouped summary cards and timestamp-oriented
  layout) is replaced; screenshots and docs that pinned old class names should
  use the new rail.
- Stale-turn recovery runs only at app startup, when nothing can legitimately be
  in flight.
- HSTS max-age starts low so the policy can be verified and raised later.
- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 33 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 33 data remains compatible with Alpha 34. Update from Gyro or replace the
existing application with the matching Alpha 34 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.33`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.33).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34/gyro-cli-0.1.0-alpha.34-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34/gyro-cli-0.1.0-alpha.34-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
