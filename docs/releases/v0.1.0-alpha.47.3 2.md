# Gyro v0.1.0-alpha.47.3

Gyro Alpha 47.3 makes Grok 4.6 the default xAI model, keeps permission choices,
and makes Source Control and completed chats easier to read.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.3/Gyro_0.1.0-alpha.47.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.3/Gyro_0.1.0-alpha.47.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.3/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Grok 4.6 is the default xAI model, with `xhigh` reasoning and a 500,000-token
  context window. A saved Grok 4.5 choice is kept.
- Source Control shows a history graph with branch and tag refs, resizable
  sections, ahead/behind counts, and addition/deletion totals.
- The permission mode you choose is saved and restored after relaunch. Full
  Access stays visually distinct in the composer.
- Completed run timelines stay visible instead of folding away. Stopped turns
  no longer show a redundant problem banner.
- Turns start with a fast workspace check for folder, project kind, and Git, so
  the first model token does not wait on a full catalog.
- File changes from a command stay attached to that command's turn. Queued
  messages wait while a chat is paused.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Grok 4.6 requires an xAI account that can use that model.
- Workspace checks are bounded. Slow Git degrades the brief instead of blocking
  the first token; a missing project folder fails closed.
- Ask First, Auto Approve, and Full Access persist as a user preference. Plan
  and Council keep their existing tool restrictions.
- Cursor and OpenCode remain experimental.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.3 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.2).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.3/gyro-cli-0.1.0-alpha.47.3-aarch64-apple-darwin.tar.gz)
and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.3/gyro-cli-0.1.0-alpha.47.3-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
