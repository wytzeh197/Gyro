# Gyro v0.1.0-alpha.46

Gyro Alpha 46 makes everyday controls simpler: clearer approval cards and
reasoning-effort choices, easier Git branch switching and renaming, and a
source-control sidebar with changes and commit history in view.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.46/Gyro_0.1.0-alpha.46_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.46/Gyro_0.1.0-alpha.46_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.46/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Clearer chat controls.** Redesigned inline approval cards and a compact
  reasoning-effort selector make choices easier to read.
- **Easier branch workflow.** Rename the current branch and switch branches
  while keeping local edits when Git can do so safely. Conflicting switches
  are still refused.
- **Source control at a glance.** Working changes and scrollable commit history
  share the sidebar, with branch and tag labels visible in history.
- **Updated model choices.** Added GPT-6 Astra and Claude Fable 5.1 to the
  provider catalog, including Astra reasoning-effort options.
- **Quieter notifications.** Approval and automation notifications defer to
  Gyro while one of its windows is visible and focused.
- **Workspace polish.** Refined settings help, branch dialogs, and chat styling.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- A provider chat still requires a configured account or locally installed
  model.
- Workspace actions require a user-selected project folder.

## Upgrade and rollback

Alpha 45 data remains compatible with Alpha 46. Update from Gyro or replace the
application with the matching Alpha 46 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.45`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.45).
Existing local sessions remain available after the rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.46/gyro-cli-0.1.0-alpha.46-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.46/gyro-cli-0.1.0-alpha.46-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
