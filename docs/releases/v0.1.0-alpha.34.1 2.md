# Gyro v0.1.0-alpha.34.1

Gyro Alpha 34.1 is a hotfix for the in-thread composer. Alpha 34 could draw the
message box as a one-character-wide vertical strip with the "Describe…"
placeholder stacked letter-by-letter; this build restores the normal full-width
composer.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.1/Gyro_0.1.0-alpha.34.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.1/Gyro_0.1.0-alpha.34.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.1/SHA256SUMS)

## What changed

- **Composer width restored.** The thread composer dock no longer centers its
  children with flex `align-items: center` while the shell uses size
  containment and a zero min-width. That combination could shrink the shell to
  a single character column. The dock now stretches full width, the shell keeps
  a solid min-width, and the canvas row template is fixed for transcript + dock.
- All other Alpha 34 behaviour is unchanged.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 34 data remains compatible with Alpha 34.1. Update from Gyro or replace
the existing application with the matching Alpha 34.1 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.34`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.1/gyro-cli-0.1.0-alpha.34.1-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.1/gyro-cli-0.1.0-alpha.34.1-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
