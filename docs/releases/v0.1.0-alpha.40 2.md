# Gyro v0.1.0-alpha.40

Gyro Alpha 40 adds private, local Ollama conversations, improves the chat
workspace's side tools, and makes model selection calmer and more legible.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.40/Gyro_0.1.0-alpha.40_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.40/Gyro_0.1.0-alpha.40_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.40/SHA256SUMS)

## What changed

- **Ollama is now a first-class local provider.** Gyro discovers models already
  installed in Ollama, with no API key and no model download performed by
  Gyro. The default endpoint is `http://localhost:11434/api`; only explicitly
  configured loopback HTTP endpoints are accepted. Redirects, remote hosts,
  credentials in URLs, and attachments are rejected.
- **Desktop Ollama runs use Gyro's normal approval boundary.** Models that
  advertise native function calling can request the existing workspace tools,
  with every action still governed by Gyro's approval policy. Models without
  verified tool support are clearly limited to chat. The `gyro` CLI supports
  text-only Ollama conversations using the same local session history.
- **The side tools fit the workspace they occupy.** Browser, Changes, and
  Terminal now reflow in a resizable chat rail, preserve a usable width when
  reopening the app, and provide a clear route back to the environment
  launcher. Empty changes and terminal states no longer show inactive controls
  or redundant chrome.
- **Model settings are easier to navigate.** The composer combines model and
  reasoning effort in one concise control, with focused menus for model,
  effort, and provider choices rather than a flat, crowded picker.
- **Docs and the download site reflect the local-first path.** The public
  guidance now explains how to connect a locally installed Ollama runtime and
  links to the product roadmap.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 39 sessions remain compatible; no destructive data migration
  is required.
- Ollama is local-only in this release. Start Ollama and pull the model you
  want before connecting Gyro; a runtime with no installed models remains
  unavailable for chat.
- Ollama attachments are not supported. Its desktop tool access depends on the
  selected model advertising function calling; CLI Ollama runs are text-only.
- Provider usage windows remain unavailable for Ollama, so no invented usage
  number is shown.

## Upgrade and rollback

Alpha 39 data remains compatible with Alpha 40. Update from Gyro or replace
the application with the matching Alpha 40 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.39`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.39).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.40/gyro-cli-0.1.0-alpha.40-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.40/gyro-cli-0.1.0-alpha.40-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
