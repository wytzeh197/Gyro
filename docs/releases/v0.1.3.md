# Gyro v0.1.3

Gyro 0.1.3 improves image attachments, command failure diagnostics, dictation,
and long chat histories. It also refines Settings, workflows, theme consistency,
and the Environment panel.

## What changed

- Image drag and drop more reliably targets the receiving composer and retains
  pending attachments while media finishes loading.
- Failed commands retain their exit code and a bounded, redacted output excerpt
  in live and saved chat activity. A successful retry keeps the earlier failure
  available for inspection.
- Dictation retains words spoken before a pause while allowing corrections to
  the current utterance.
- Long conversations load bounded history pages, with older events still
  accessible. Approved file changes avoid briefly resurfacing as new approvals.
- Answered questions clear promptly, and a new task clears stale Environment
  plan progress while retaining the saved plan document.
- Settings, workflow lists and run details, and companion surfaces receive
  layout and theme refinements. Environment reserves reading space beside a
  single chat; split panes retain their overlay behavior.
- Session branches start from the current local branch, and the composer hides
  its branch chip outside Git repositories.

## Download and install

Requires macOS 14+ on Apple Silicon or Intel. Release app bundles and DMGs are
signed with Gyro's Developer ID and notarized by Apple. macOS may ask you to
confirm the first opening of an app downloaded from the internet.

Use [the download site](https://usegyro.io/) or the exact architecture download:

- [Apple Silicon: Gyro_0.1.3_aarch64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.3/Gyro_0.1.3_aarch64.dmg)
- [Intel: Gyro_0.1.3_x64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.3/Gyro_0.1.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.3/SHA256SUMS)

Match the checksum to the exact filename. Follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md)
(`docs/install-macos.md`).

## Behavior and known limits

Local work and user-owned provider connections remain available without a Gyro
account. Account, Plan & billing, and Cloud remain coming-soon settings; this
release does not enable hosted sign-in, purchases, uploads, sharing, or managed AI.

Second-opinion reviews require supported API or Ollama connections; CLI adapters
are not supported for the advisory review step. Workflows run in local checkouts
or separately opened external worktrees. Gyro-managed private worktree execution
remains unavailable. Provider support depends on the installed provider, account,
model, and configuration. Cursor and OpenCode remain experimental.

## Upgrade and rollback

Quit Gyro and back up `~/Library/Application Support/Gyro/` before upgrading or
rolling back. Back up project `.gyro/` directories too. Install the matching DMG
or use the signed in-app updater. Verify that sessions, provider settings, project
memory, and workflows survive the update before removing backups.

To roll back, quit Gyro and manually reinstall
[v0.1.2](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.2).
The updater does not perform downgrades. Restore the matching backup if the older
build cannot read newer data; cross-version downgrade acceptance has not been
established. When replacing an older ad-hoc build for the first time, grant
Accessibility again if requested; a one-time Keychain prompt may also appear.

## CLI

Keep app and CLI versions aligned when handing sessions between them:

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.3/gyro-cli-0.1.3-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.3/gyro-cli-0.1.3-x86_64-apple-darwin.tar.gz)

Each archive has a `.sha256` sidecar. The release includes the generated `gyro.rb`
Formula. After the validated Formula reaches the tap:

```sh
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only.
