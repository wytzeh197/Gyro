# Gyro v0.1.0-preview.2

Gyro 0.1.0-preview.2 is the next signed build of the v0.1.0 app. A project
can hold extra folders, a reply can start a separate task in its own chat,
and a missing provider CLI shows an install command. It opens with Apple's
normal downloaded-app prompt.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. This preview is signed with
Gyro's Developer ID and notarized by Apple. It opens after the standard
"downloaded from the internet" prompt.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.2/Gyro_0.1.0-preview.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.2/Gyro_0.1.0-preview.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.2/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

Moving from v0.1.0-preview.1 keeps the same signing identity. macOS may
prompt once for an older Keychain item that holds a saved provider key. Choose
Always Allow if that prompt appears. New keys are saved on this Mac.

## What changed

- **A project can hold extra folders.** Add folders beside the original one.
  A folder that is missing, unreadable, or a duplicate stays listed. Locate…
  points a moved folder back at the project, and Remove drops one that is
  gone. An unplugged drive comes back on its own.
- **A reply can hand off a separate task.** When work is clearly separate, the
  reply can offer up to two tasks. Each one starts in its own chat and can be
  edited or dismissed before it starts.
- **Missing CLIs show how to install.** A provider whose command is not on
  this Mac shows the vendor install command. Gyro runs it only after you
  confirm.
- **Background notices follow Settings.** Approval, finished, and failed
  notices are sent only when Gyro is not the focused app, and only when macOS
  has actually allowed notifications. The text stays generic.
- **Compact stays out of the chat.** A `/compact` summary is no longer
  streamed in as a reply. The compaction row still shows.
- **The model and effort controls sit in the rail.** The settings gear stays
  below the provider logos, hidden rows fade instead of cutting in half, and
  Fast mode is a labelled toggle.
- **Claude's 5-hour limit stays visible while idle.** An idle session beside a
  measured week reads as a full 5-hour allowance. A window past its reset
  shows 0% used instead of disappearing.
- **The empty screen lists recent projects.** Opening one keeps a prompt you
  already typed. The send button keeps its size on Comfortable density.
- **Light and dark settings match the rest of the app.** Switches, segmented
  controls, and the Appearance page use the same surfaces as the canvas.

## Behavior changes and known limits

- After this preview is published, the download site and the in-app updater
  follow it. It is the latest release. Install the DMG above if an older app
  does not offer the update yet.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. Keep app and CLI versions aligned when handing sessions between them.
- A reply offers at most two tasks, and only for work that is separate from
  the current request. The original project folder cannot be removed.
- An install command never runs by itself.

## Upgrade and rollback

Install the matching 0.1.0-preview.2 DMG. Before changing versions, quit Gyro
and back up `~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-preview.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-preview.1).
Keep the backup until you have verified your sessions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.2/gyro-cli-0.1.0-preview.2-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.2/gyro-cli-0.1.0-preview.2-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key. App bundles and DMGs are signed with Gyro's Developer ID and notarized by
Apple.
