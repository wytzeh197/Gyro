# Gyro v0.1.0-alpha.34.3

Gyro Alpha 34.3 polishes the in-chat run rail and final answer: plan lines stay
under the work header, orphan stream fragments disappear, and tool rows name
what ran instead of repeating "xAI tool".

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.3/Gyro_0.1.0-alpha.34.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.3/Gyro_0.1.0-alpha.34.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.3/SHA256SUMS)

## What changed

- **Final answers stay clean.** Plan and status lines ("I'll look up…") peel
  into the collapsible work rail. Stream garbage such as a lone `e.` is dropped.
- **Tool rows are specific.** ACP tools without a title use kind + path/query
  (for example `Read README.md`) instead of a bare `{provider} tool` label.
  Generic placeholders no longer render as `Used tool · xAI tool`.
- **Hover tooltips** only appear when they add detail beyond the visible row.
- Composer width fix from 34.2 is unchanged.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34.x sessions remain compatible.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 34.3 DMG.
To roll back, reinstall
[`v0.1.0-alpha.34.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.2).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.3/gyro-cli-0.1.0-alpha.34.3-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.3/gyro-cli-0.1.0-alpha.34.3-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
