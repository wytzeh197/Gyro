# Gyro v0.1.0-alpha.33

Gyro Alpha 33 deepens the Workspace AI and Source Control experience. Chat
lives inside the AI activity view without throwing you out of the code layout,
and Source Control reads like a normal editor SCM panel: staged and unstaged
groups, language-coloured file icons, git decoration letters, and live refresh.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.33/Gyro_0.1.0-alpha.33_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.33/Gyro_0.1.0-alpha.33_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.33/SHA256SUMS)

## What changed

- **AI view is the workspace chat.** Selecting AI in the activity rail opens
  the same chat surface Sessions uses, at a wider sidebar width, with a chat
  switcher for recent project conversations and New chat — all without leaving
  the code layout.
- **Stay in the code layout.** Starting a chat, switching sessions, or sending
  a first message from the AI view keeps Workspace in code layout. Thread
  layout is still used when chat is opened from Sessions or destinations that
  need the full thread surface.
- **Assistant toggle selects AI, not a second panel.** The editor assistant
  action toggles the AI activity view versus Explorer instead of a separate
  right-side assistant surface.
- **VS Code-style Source Control groups.** Changes split into collapsible
  **Staged Changes** and **Changes** groups, with batch stage / unstage /
  discard actions on each group header.
- **Partly staged files appear twice.** Git’s index and worktree sides are
  listed separately, so a file with staged and unstaged edits shows under both
  groups — matching VS Code’s SCM behaviour.
- **Language icons and git decoration letters.** Each SCM row carries a
  language-coloured file icon and a short git state letter (M, A, D, R, U, ?)
  so the panel scans by colour first.
- **Live Source Control.** Status loads as soon as a workspace root is known,
  and refreshes every few seconds while the Source Control view is visible so
  external edits, rebases, and terminal git stay honest.
- **Activity rail change badge.** The Source Control rail icon shows a pending
  change count (capped at 99+).
- **Repository and branch side by side.** The SCM header keeps repository name
  and branch picker on one row without wrapping on normal sidebar widths.
- **Search in Files.** The command palette entry is renamed to **View: Search
  in Files** for clearer discoverability.

## Behavior changes and known limits

- The removed `rightAssistantOpen` layout flag is no longer restored from
  saved IDE state; opening AI always goes through the activity rail view.
- Source Control still requires a trusted workspace and a real Git repository.
  Detached HEAD and non-repo folders report that state honestly.
- External git updates are polled only while Source Control is the active IDE
  view; switching away stops the interval.
- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 32 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 32 data remains compatible with Alpha 33. Update from Gyro or replace the
existing application with the matching Alpha 33 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.32`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.32).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.33/gyro-cli-0.1.0-alpha.33-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.33/gyro-cli-0.1.0-alpha.33-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
