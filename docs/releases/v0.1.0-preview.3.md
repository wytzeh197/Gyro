# Gyro v0.1.0-preview.3

Gyro 0.1.0-preview.3 improves provider setup, chat and workspace reliability,
settings, and local usage reporting. The Browser panel adds snapshot inspection
for macOS windows and booted iPhone Simulators. Local Check lets you review a
command or browser check before it runs. Native preview interaction and Local
Check still have the acceptance limits described below.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. This preview is signed with
Gyro's Developer ID and notarized by Apple. It opens after the standard
"downloaded from the internet" prompt.

Use the [Gyro download site](https://usegyro.io/) to choose your build and follow
the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.3/Gyro_0.1.0-preview.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.3/Gyro_0.1.0-preview.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.3/SHA256SUMS)

Match the checksum to the exact filename you downloaded. Moving from an older
ad-hoc build requires granting Accessibility again, and macOS may ask once for
access to an older Keychain item. Moving from preview.2 retains the same signing
identity; confirm that against the final artifacts before publication.

## What changed

- **Provider setup is clearer.** Sign-in progress, missing-CLI installation,
  first-run guidance, and provider defaults help set up a local account.
- **Chat and workspace behavior is more consistent.** File and image actions,
  folder refresh, search, task suggestions, and split-chat drop handling have
  reliability fixes. Git comparison totals leave out unrelated untracked files.
- **Settings have more local controls.** New-chat defaults, settings transfer,
  disclosure state, notification details, and help are available in Settings.
- **The Browser panel can inspect app snapshots.** Choose a macOS window or a
  booted iPhone Simulator, capture it, and inspect the result alongside Web.
  Capture-bound macOS clicks require permission and a current verified target.
- **Local Check is an experimental review flow.** Review the local target,
  command or browser steps, expected results, and possible changes before
  confirming a run. Reports retain the scope of the evidence collected.
- **Provider execution and usage reporting have targeted fixes.** Tool schemas,
  image handling, retries, request accounting, and efficiency controls have been
  updated. Claude receives Gyro tool schemas up front and cannot use its native
  external publishing or scheduling tools through this integration.

## Behavior changes and known limits

- This is a preview. Native app inspection and Local Check have partial
  acceptance only. Native window capture/click acceptance requires Screen
  Recording and Accessibility; iPhone inspection needs full Xcode and a booted
  Simulator. Simulator touch injection is not implemented. Snapshots are not a
  live video stream. See [App Preview](https://github.com/wytzeh197/Gyro/blob/main/docs/features/app-preview-inspection.md)
  and [Local Check](https://github.com/wytzeh197/Gyro/blob/main/docs/features/local-check.md).
- A passing command or structured browser check covers its reviewed assertions;
  it does not establish complete visual quality or correctness.
- Usage can be estimated or unavailable when a provider does not report it.
  Local budgets are not invoice limits. No general live-provider cost or quality
  improvement is established by this release.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. Keep app and CLI versions aligned when handing sessions between them.
- The download site and updater select this version only after publication.

## Upgrade and rollback

Update from Gyro or install the matching 0.1.0-preview.3 DMG. Quit Gyro and back
up `~/Library/Application Support/Gyro/` before changing versions. To roll back,
reinstall [v0.1.0-preview.2](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-preview.2).
Keep the backup until you have verified your sessions; data written by newer
features is not guaranteed to be readable by an older app. Restore a backup
only while both the app and CLI are stopped.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.3/gyro-cli-0.1.0-preview.3-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.3/gyro-cli-0.1.0-preview.3-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key. App bundles and DMGs are signed with Gyro's Developer ID and notarized by
Apple.
