# Gyro v0.1.0-alpha.47.7

Gyro Alpha 47.7 improves usage reporting, project controls, and everyday chat and workspace interactions.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.7/Gyro_0.1.0-alpha.47.7_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.7/Gyro_0.1.0-alpha.47.7_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.7/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Models can wait for a running command to finish and then continue the task,
  including release watchers for Intel and Apple Silicon builds.

- Usage indicators retain cached readings when refresh fails, mark stale data,
  and discard allowance windows after their reset.
- Queue steering and retry put the selected message next in line.
- The chat Environment panel handles solo and tiled chats consistently.
- Project cards support editing names, pinning, managing folders, and choosing
  a primary folder.
- Source-control review displays workspace-relative paths and clearer change
  totals with dedicated file actions.
- The terminal drawer uses a compact tab strip; Appearance has theme previews.
- Settings controls and the download site's layout receive usability fixes.
- Window chrome and streamed text block boundaries are refined.

## Behavior changes and known limits

- Command waiting requires Gyro to remain open with the chat turn active and
  remains subject to provider runtime and usage limits.

- Alpha app bundles remain ad-hoc signed and not notarized.
- Provider plan usage depends on the provider's available reporting; cached
  readings are not a live guarantee of remaining allowance.
- Native provider connections, OS folder pickers, permissions, and updater
  installation require desktop acceptance in addition to automated checks.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.7 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.6`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.6).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.7/gyro-cli-0.1.0-alpha.47.7-aarch64-apple-darwin.tar.gz)
and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.7/gyro-cli-0.1.0-alpha.47.7-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
