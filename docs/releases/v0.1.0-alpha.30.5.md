# Gyro v0.1.0-alpha.30.5

Gyro Alpha 30.5 separates intermediate work from the final answer in chat,
even when a provider glued them into one bubble. It also makes Grok multi-turn
more reliable, swaps the broken xAI glyph for the Grok monochrome mark, and
softens the run timeline so work reads quiet and the answer stays the focus.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.5/Gyro_0.1.0-alpha.30.5_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.5/Gyro_0.1.0-alpha.30.5_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.5/SHA256SUMS)

## What changed

- **Glued intermediate and final answers split again.** When a provider
  concatenates blocks without a break (`edits.Now the…`, `is.Gyro is…`,
  including bolded openers like `is.**Gyro…**`), Gyro recovers separate
  timeline blocks and paragraphs — even on older turns that never recorded
  stream segment marks.
- **New text after tools gets a real break.** Streaming and the desktop
  runtime insert a paragraph separator when a fresh content block resumes
  mid-sentence, so the next block does not fuse onto the previous period.
- **Hidden control markers survive multi-block streams.** Title, plan, and
  artifact markers are stripped in one pass (including markers glued mid-line),
  so a later marker is not dropped after an earlier one is removed.
- **Run timeline is quieter.** Mid-run narration is muted body copy rather than
  a heavy final answer. Work steps drop the clock rail and spine, use short
  human labels ("Ran a command", "Ran 3 tools"), and show a wrench for tools
  instead of a sparkle.
- **Final answer weight matches reading, not shouting.** Run responses use
  normal weight and size so the answer does not look like a thick title block.
- **Grok multi-turn is more reliable.** The xAI agent launches with
  Synara-compatible flags (`--no-leader`, permission mode, model and effort on
  the process). When session resume is missing or fails, Gyro opens a fresh ACP
  session and injects prior chat history so follow-ups keep context.
- **Grok mark and picker layout.** The provider chip uses the monochrome Grok
  mark (theme-aware, solid on light and dark) instead of an X-shaped smudge.
  Provider and model menus sit side-by-side and grow from the chip so the
  models panel stays on-screen.

## Behavior changes and known limits

- Glue recovery only splits at the unmistakable sentence-end-plus-capital
  boundary. Ordinary prose, versions, and paths are left alone; rare false
  positives can still insert a break if a provider ends a sentence hard against
  a capital without a space.
- Segment marks remain preferred when the stream recorded them. Glue recovery
  is the fallback for missing or invalid marks.
- Grok still depends on the local `grok` / xAI CLI. Agents that never advertise
  resume continue to use history injection on every follow-up that needs a new
  session.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 30.4 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 30.4 data remains compatible with Alpha 30.5. Update from Gyro or replace
the existing application with the matching Alpha 30.5 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.30.4`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.30.4).

## CLI

The CLI picks up the same xAI agent launch flags and remains version-aligned
with the app. After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.5/gyro-cli-0.1.0-alpha.30.5-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.5/gyro-cli-0.1.0-alpha.30.5-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
