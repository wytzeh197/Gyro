# Gyro v0.1.0-alpha.48.1

Gyro Alpha 48.1 makes source-control review clearer and keeps large diffs
readable, with workspace search and chat layout refinements.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.1/Gyro_0.1.0-alpha.48.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.1/Gyro_0.1.0-alpha.48.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.1/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Review now shows whether a change is against `main`, the index, or the working
  tree, and opens the file list that matches that scope.
- Large or unsupported files use a bounded, paginated text diff when the rich
  editor cannot render them. Review also reports an honest empty or unavailable
  state instead of showing a blank editor.
- Workspace search presents matching lines with file and line context.
- Chat companion sizing keeps a usable transcript width and overlays Review in
  narrow panes. Several chat and browser controls have more compact layouts.
- ACP screenshot sending, plan rendering, and macOS window-control alignment
  receive reliability fixes.

## Behavior changes and known limits

- Branch comparisons use the last fetched `origin/main` when available, then
  fall back to the local `main` ref. Refresh Git refs to compare against the
  latest remote state.
- Plain text review is bounded and may truncate very large diffs; open the file
  to inspect content beyond the displayed hunks.
- Provider connections, native permissions, clean-user installation, and
  updater behavior require desktop acceptance beyond automated regression
  tests.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.1 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48).
This release does not introduce a session schema migration; older versions do
not include the new review scopes or workspace search presentation.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.1/gyro-cli-0.1.0-alpha.48.1-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.1/gyro-cli-0.1.0-alpha.48.1-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
