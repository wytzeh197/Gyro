# Gyro v0.1.0-alpha.48.8

Gyro Alpha 48.8 gives the model real code intelligence and stops the browser
from taking your screen. Chats can now resolve a definition, find references, or
read a symbol's hover documentation through the same language servers the editor
uses, including in files nobody opened. Model-driven browsing runs behind the
chat instead of revealing the Browser panel over the transcript you were
reading. It also adds durable project memory, read-only Git history, a bounded
web fetch, and a research sub-agent.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.8/Gyro_0.1.0-alpha.48.8_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.8/Gyro_0.1.0-alpha.48.8_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.8/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Code intelligence.** Chats can resolve a definition, list references, read
  hover documentation, and enumerate document symbols through the workspace's
  managed language servers. The editor and the model share one server pool, so a
  chat does not start a second copy of your language server. A cold server
  reports that it is still indexing rather than answering "not found".
- **The browser stays out of the way.** A model navigation no longer reveals the
  Browser panel by default. Gyro's browser is a native child webview, so the
  model reads a page through the agent bridge while an unrevealed browser keeps
  a full desktop viewport — in a split layout, one chat's tool call no longer
  covers the transcript you were reading in the other pane.
- **Project memory.** A chat can keep notes that survive it, stored as
  `.gyro/memory.md` in the workspace: a visible, editable, diffable file that
  travels with the project rather than a private database. Writes go through the
  same review path as any other workspace edit.
- **Read-only Git history.** `gyro_git_log`, `gyro_git_show`, and
  `gyro_git_blame` let a chat read history without touching the working tree.
  Every call builds an argument list rather than a shell string, so a revision
  or path is data and never syntax.
- **Bounded web fetch.** A chat can read a URL without opening a webview: GET
  only, text content types only, a hard byte ceiling, secret redaction, and a
  bounded redirect chain whose final URL is always reported.
- **Research sub-agent.** `gyro_research` runs one bounded, read-only provider
  turn in a fresh context and returns only its final message. It runs in Plan
  mode, so the existing read-only capability policy applies and a sub-agent
  cannot start another one. The child session is kept, so the research is
  auditable.
- **Targeted workspace edits.** Alongside whole-file proposals, a chat can
  replace an exact string inside a file it already read, instead of re-emitting
  an entire file to change three lines. Both shapes land in the same proposal
  store with the same hash guard, review, and durable decision. Chats can also
  create, rename, move, and delete files through the same root-asserted helpers
  the Workspace explorer uses.
- **Repository actions from the Environment popover.** Two coarse rows — move
  the work forward, or publish it — close the gap where the popover reported
  three uncommitted files and then left you to find the Review surface yourself.
- **Steadier provider requests.** A transient HTTP failure is retried on a short
  backoff at the request level, never by replaying an agent's already-executed
  tool loop.
- **Interface corrections.** The project hover card and edit dialog now use
  Gyro's warm neutral surfaces instead of a flat white panel, and the docked
  composer's add button lost a stray resting fill that the hero composer never
  had.

## Behavior changes and known limits

- Code intelligence depends on a language server being installed and resolvable
  for the workspace's language. Where none is available, navigation requests
  report that rather than falling back to a text search.
- The first navigation in a cold workspace can return an indexing result while
  the server warms up; retry once it has settled.
- Model navigation no longer reveals the Browser panel. Open the Browser surface
  yourself to watch a chat browse.
- Project memory is a workspace file. It is not encrypted, and it is committed
  by you like any other file — keep secrets out of it.
- `gyro_research` spends provider tokens on its own turn and blocks the parent
  tool call until it finishes.
- This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.8 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.7`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.7).
This release adds new capability records and an optional workspace memory file;
it does not introduce a session schema migration, and an older build ignores
what it does not recognize.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.8/gyro-cli-0.1.0-alpha.48.8-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.8/gyro-cli-0.1.0-alpha.48.8-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
