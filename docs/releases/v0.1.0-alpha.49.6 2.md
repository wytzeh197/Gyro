# Gyro v0.1.0-alpha.49.6

Gyro Alpha 49.6 expands the shared chat and workspace workflow with stronger
session context, more reliable scheduled work, clearer usage controls, browser
inspection, and smoother provider streaming. It also adds an in-app summary of
what changed after an update.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.6/Gyro_0.1.0-alpha.49.6_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.6/Gyro_0.1.0-alpha.49.6_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.6/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Chat and session context are more consistent.** Chats keep their selected
  model and goal, transcript scrolling and turn tokens are steadier, and session
  lists surface completion and unread state more reliably. Browser capture and
  file handoff make it easier to bring observed page content into a session.
- **Scheduled and delegated work recovers more cleanly.** Automation state,
  receipts, and leases survive interruptions; subagents and provider runs use
  clearer capability boundaries and recover better from stream ordering issues.
- **Workspace tools expose more useful context.** Browser controls, language
  server discovery, session browsing, and workspace capabilities are more
  consistent. Usage actions and context compaction make long-running work easier
  to manage.
- **Provider and CLI workflows are more dependable.** Kimi ACP, Ollama, and
  OpenAI-compatible runs handle context and streaming more carefully, while app
  and CLI sessions continue to share their local store.
- **Updates explain themselves.** After a successful update, Gyro can show the
  release notes for the installed version in a dismissible What's New notice.

## Behavior changes and known limits

- This Alpha remains ad-hoc signed and is not Apple-signed or notarized.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. This release adds a session relationship field for delegated work; an
  older version may not show those relationships. Keep matching app and CLI
  versions for session handoff.
- Model and provider behavior still depends on each provider's API and local
  runtime capabilities.

## Upgrade and rollback

Update from Gyro, or replace the application with the matching Alpha 49.6 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.5`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.5).
Keep the backup until you have verified your sessions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.6/gyro-cli-0.1.0-alpha.49.6-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.6/gyro-cli-0.1.0-alpha.49.6-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
