# Gyro v0.1.0-alpha.49.2

Gyro Alpha 49.2 refines the chat composer, workspace title bar, and split-chat
headers. It includes no session database migration.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.2/Gyro_0.1.0-alpha.49.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.2/Gyro_0.1.0-alpha.49.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.2/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Cleaner split-chat headers.** Removed the drag grip from chat headers.
  Place chats in a split layout by dragging them from the sidebar.
- **A consistent workspace title bar.** The activity rail and sidebar header
  now share one background behind the macOS window controls.
- **Refined chat styling.** Light mode uses a white composer and lighter
  message queue. The Sessions/Workspace switcher has rounded ends and a
  subtler hover treatment.

## Behavior changes and known limits

- Chat headers no longer provide a pane-rearrangement drag handle; sidebar
  dragging remains available for split placement.
- This Alpha remains ad-hoc signed and is not Apple-signed or notarized.
- Use matching app and CLI versions for session handoff.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 49.2 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.1).
This release does not add a session database schema migration. Keep the backup
until you have verified your sessions in the version you intend to use.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.2/gyro-cli-0.1.0-alpha.49.2-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.2/gyro-cli-0.1.0-alpha.49.2-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
