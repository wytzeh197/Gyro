# Gyro v0.1.0-alpha.34.5

Gyro Alpha 34.5 upgrades the chat **working** rail with real tool specifics,
keeps split-screen chats independent, hands models off without losing local
history, and fills Claude plan usage plus update size that used to show empty.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.5/Gyro_0.1.0-alpha.34.5_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.5/Gyro_0.1.0-alpha.34.5_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.5/SHA256SUMS)

## What changed

- **Working rail tool specifics.** Tool rows carry a note for what ran
  (command, path, skill name) instead of repeating machine ids like
  “Bash · Bash · Bash”. Claude Bash/Read/Grep reclassify onto command, file,
  and search rows when input is available.
- **Answer-first history.** Fully answered turns auto-collapse once they settle;
  incomplete stops stay open. Observation-then-“Let me…” plan lines peel onto
  the rail without double-drawing.
- **Split-screen models.** Each chat pane keeps its own provider/model
  (including new drafts). Closing a split pane compacts the remaining chat and
  focuses it cleanly.
- **Model handoff continuity.** Switching model or provider on a local session
  clears foreign resume cursors and injects local history into a fresh agent
  session so the next model can continue the same thread.
- **Claude plan usage.** Composer plan windows read live utilization from
  Anthropic’s account usage endpoint via Claude Code credentials (not only
  reset times from the stream).
- **Context meter across models.** Occupancy follows the thread when you switch
  models; the window comes from the model selected now.
- **Update tip.** The titlebar update control shows version and download size
  (from `latest.json`) before and during download.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34.x sessions remain compatible.
- Claude plan percentages require a valid Claude Code sign-in on the machine.
- Tool notes depend on provider stream input; early tool-start frames may still
  show the tool name until the completed input arrives.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 34.5 DMG.
To roll back, reinstall
[`v0.1.0-alpha.34.4`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.4).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.5/gyro-cli-0.1.0-alpha.34.5-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.5/gyro-cli-0.1.0-alpha.34.5-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
