# Gyro v0.1.0-alpha.29.3

Gyro Alpha 29.3 extends executable agent support beyond Codex CLI and Claude
Code to Kimi Code, Gemini CLI, and Grok Build, each through a provider-owned
local login.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.29.3/Gyro_0.1.0-alpha.29.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.29.3/Gyro_0.1.0-alpha.29.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.29.3/SHA256SUMS)

## What changed

- Kimi Code, Gemini CLI, and Grok Build are now executable adapters through the
  shared ACP runtime, joining Codex CLI and Claude Code. Each runs against the
  provider's own local login rather than an API key held by Gyro.
- These providers now support approvals, images, and session resume, and appear
  as standard providers instead of readiness-only entries.
- xAI now targets Grok 4.5 through Grok Build.
- Provider health checks and the provider registry report CLI login state for
  the new adapters, including the provider-specific login command to run when a
  session is not connected.
- The CLI reports clearer exit codes for provider and session failures, with
  test coverage for those paths.
- The new-session menu shows each provider's own logo instead of a generic agent
  icon, and the Claude mark now renders from the official artwork without
  clipping.
- Sessions, provider marks, and the workspace titlebar received contrast and
  alignment fixes in both light and dark themes.
- Product documentation and the download site were repositioned around the
  unified coding workflow.

## Behavior changes and known limits

- Kimi Code, Gemini CLI, and Grok Build must be installed and logged in through
  their own tools. Gyro does not install these CLIs and never takes ownership of
  provider credentials, plans, or billing.
- Cursor and OpenCode remain clearly marked until their approval-safe adapters
  exist.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 29 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 29 data remains compatible with Alpha 29.3. Update from Gyro or replace
the existing application with the matching Alpha 29.3 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.29.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.29.2).

## CLI

This release adds provider and session exit-code reporting for CLI-driven
sessions. After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew trust --formula wytzeh197/tap/gyro
brew install gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.29.3/gyro-cli-0.1.0-alpha.29.3-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.29.3/gyro-cli-0.1.0-alpha.29.3-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
