# Gyro v0.1.0-alpha.47.1

Gyro Alpha 47.1 replaces the faulty Alpha 47 release with corrected permission
handling and a simpler workspace working view.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.1/Gyro_0.1.0-alpha.47.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.1/Gyro_0.1.0-alpha.47.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.1/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Full access now means full access.** Normal chats no longer request
  capability approval for terminal actions after you choose Full access.
- **Clearer working view.** Workspace reads show the active file in the
  working-process list; the redundant strip above the composer is gone.
- **Mission Control removed.** New mission controls and mission worker screens
  have been removed. Existing worker terminals remain available as normal CLI
  sessions.
- **Cleaner sidebar.** Empty placeholder chats do not reappear after metadata
  updates.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Full access applies to normal chats. Plan and Council retain their existing
  tool restrictions.
- A provider chat requires a configured account or locally installed model.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.1 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.1/gyro-cli-0.1.0-alpha.47.1-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.1/gyro-cli-0.1.0-alpha.47.1-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
