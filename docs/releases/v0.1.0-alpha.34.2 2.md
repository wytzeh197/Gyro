# Gyro v0.1.0-alpha.34.2

Gyro Alpha 34.2 finishes the in-thread composer width fix. Alpha 34.1 stopped
centering the dock, but still used a percentage-based min-width
(`min(100%, 280px)`). Under size containment that percentage resolves to `0` in
a cyclic layout, so the message box could still collapse to a one-character
vertical strip with the "Describe…" placeholder stacked letter-by-letter.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.2/Gyro_0.1.0-alpha.34.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.2/Gyro_0.1.0-alpha.34.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.2/SHA256SUMS)

## What changed

- **Composer width hardened.** The thread dock keeps `align-items: stretch` at
  the source rule (not only a later override). The shell uses a definite
  `min-width: 280px` floor instead of a percentage min-width, centers with
  `margin-inline: auto` instead of `align-self: center`, and the canvas
  establishes a definite column (`minmax(0, 1fr)`) so width comes from the
  surface rather than content under size containment.
- Narrow contexts (Workspace AI sidebar, tiled panes) still allow `min-width: 0`
  so the floor does not force horizontal overflow.
- All other Alpha 34.1 behaviour is unchanged.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34 / 34.1 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 34 data remains compatible with Alpha 34.2. Update from Gyro or replace
the existing application with the matching Alpha 34.2 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.34.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.1).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.2/gyro-cli-0.1.0-alpha.34.2-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.2/gyro-cli-0.1.0-alpha.34.2-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
