# Gyro v0.1.0-alpha.35

Gyro Alpha 35 adds in-app provider CLI updates, keeps the run rail honest
during reconnects and mid-turn narration, fixes agent workspace search so
regex patterns actually match, and polishes chat scroll, usage display, and
settled-turn tool rows.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.35/Gyro_0.1.0-alpha.35_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.35/Gyro_0.1.0-alpha.35_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.35/SHA256SUMS)

## What changed

- **Provider CLI updates.** Gyro checks Claude Code, Codex, and Grok CLIs on
  launch and periodically, then shows a center-top notice when an update is
  available. **Update** / **Update All** install only after you press the
  button — never automatically.
- **Live retry on the run rail.** Offline or provider transport loss becomes a
  live rail beat instead of a failed turn, so reconnects stay in the same run.
- **Mid-run narration stays on the rail.** Streaming narration is no longer
  promoted as the final answer while the turn is still going.
- **Agent workspace search uses regex.** Capability search accepts agent
  patterns (`stop|abort`, `cancel.*stream`) instead of fixed-string matching
  that returned zero hits and made models loop short “I'll investigate” turns.
  Invalid regex falls back to a literal search.
- **Settled turns close open tools.** When a turn finishes without a final
  activity frame, optimistic tool rows stop breathing on “running.”
- **Chat transcript follows the bottom.** Live turns keep the transcript
  pinned until you scroll up; composer/rail resizes re-seat the bottom without
  yanking a reader who left the floor.
- **Usage shows cached input.** Session spend can surface how much of each
  call’s input was already in context, without changing budget totals.
- **Run rail work polish.** File and image reads use clearer verbs, repeated
  work absorbs into one row, and the environment rail is the standing side
  panel rather than an opt-in.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34.x sessions remain compatible; no destructive data migration
  is required.
- Provider CLI updates only cover CLIs Gyro can locate on `PATH` (or the
  augmented GUI path). Install methods outside the supported check (custom
  builds, unlisted package managers) may not appear.
- UI workspace search in the app stays fixed-string; only agent/capability
  search enables regex.
- Cached input is display-only for understanding spend; ceilings and budgets
  still use the same total-token figure as before.

## Upgrade and rollback

Alpha 34.x data remains compatible with Alpha 35. Update from Gyro or replace
the application with the matching Alpha 35 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.34.6`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.6).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.35/gyro-cli-0.1.0-alpha.35-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.35/gyro-cli-0.1.0-alpha.35-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
