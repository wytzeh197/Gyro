# Gyro v0.1.0-alpha.41

Gyro Alpha 41 brings the chat workbench together around a focused, tabbed
companion dock, makes end-of-turn file review an honest reading record, and
continues the local-first reliability work in the desktop app and CLI.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.41/Gyro_0.1.0-alpha.41_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.41/Gyro_0.1.0-alpha.41_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.41/SHA256SUMS)

## What changed

- **A tabbed companion dock follows the focused chat.** Review, Terminal,
  Browser, Files, and Side chat now live beside the transcript in one dock.
  Each pane keeps its own open tabs, while the dock follows the pane you focus
  in a multi-chat grid. Narrow panes use an overlay so the transcript retains
  a readable width.
- **Side chat is deliberately temporary.** It inherits the focused chat's
  workspace, branch, model, and permission policy without inheriting its
  transcript. It is kept out of history and the sidebar, deleted when closed,
  and swept after an unclean exit.
- **Changed files get an attended review pass.** A completed turn can show one
  grounded summary per edited file, with a bounded inline diff and an optional
  Keep marker. Keep records that the current content was read; it never
  applies, reverts, or blocks a change. When Gyro cannot obtain a provider
  summary, it shows measured line counts instead of inventing prose.
- **Run and usage information stay tied to real work.** The run rail continues
  to consolidate file activity and usage accounting separates change-summary
  calls from ordinary chat usage.
- **The start screen and rail were refined.** Suggested task cards now seed a
  draft instead of sending it, and the sidebar and menu-bar surfaces share
  clearer spacing, typography, and dark/light color tokens.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- The companion dock is per focused chat pane; closing a pane drops its dock
  state and any Side chat attached to it.
- Side chat is not a durable conversation. It is intentionally omitted from
  history and sharing, and its messages disappear when the tab is closed.
- File review is not an approval queue. Changes already made by an attended
  turn remain on disk whether or not a file is marked Keep.
- Change summaries use the selected provider and count against the displayed
  provider budget. If the budget is paused, the provider is unavailable, or a
  response is unusable, Gyro falls back to factual change counts.

## Upgrade and rollback

Alpha 39 data remains compatible with Alpha 41. Update from Gyro or replace
the application with the matching Alpha 41 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.39`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.39).
Side chats are transient, so there is no Side-chat history to restore after a
rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.41/gyro-cli-0.1.0-alpha.41-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.41/gyro-cli-0.1.0-alpha.41-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
