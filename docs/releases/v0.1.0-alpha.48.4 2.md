# Gyro v0.1.0-alpha.48.4

Gyro Alpha 48.4 is a polish release: shell edits made by Claude now appear in a
turn's changed files, attaching files takes one picker, and the composer and
sidebar lose visual noise.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.4/Gyro_0.1.0-alpha.48.4_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.4/Gyro_0.1.0-alpha.48.4_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.4/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Files that Claude edits through shell commands (for example `sed -i` or a
  script) now appear in the turn's changed files, limited to paths named in
  the command inside the project.
- Edits proposed through Gyro's own edit tool count as changed files.
- One **Attach files** picker accepts images, videos and project files; the
  Editor option only appears when an open project file can be captured.
- Dropping or pasting HEIC, GIF, TIFF, BMP or AVIF media reaches the attachment
  step, which names unsupported files instead of silently ignoring the drop.
- Hovering a model in the picker no longer opens the context card over it.
- Flatter sidebar mode switch, no duplicate change badge in the environment
  popover, and traffic lights aligned one pixel lower.
- Opening Workspace from the sidebar or search no longer pulls the open chat
  into the AI side panel.
- Lower memory use while tracking shell edits during long turns.

## Behavior changes and known limits

- Shell edits are only detected for literal file paths in the command;
  generated or computed paths are not attributed to the turn.
- Automated checks cover the file tracking and attachment rules. Native visual
  acceptance and in-app upgrade behavior still require desktop verification.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.4 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.3).
This release does not introduce a session schema migration; older versions do
not include shell edit tracking or the unified attach picker.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.4/gyro-cli-0.1.0-alpha.48.4-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.4/gyro-cli-0.1.0-alpha.48.4-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
