# Gyro v0.1.0-alpha.49.7

Gyro Alpha 49.7 improves appearance controls and provider reliability, refreshes
the download site's product visuals, and makes new-chat recovery safer when a
session cannot be written to disk.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.7/Gyro_0.1.0-alpha.49.7_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.7/Gyro_0.1.0-alpha.49.7_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.7/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Appearance controls are more complete.** Choose interface size and animation
  speed alongside theme, density, and colors. The settings carry through the
  editor and terminal, and reduced-motion preferences are respected.
- **Provider requests recover more carefully.** HTTP cancellation, bounded
  retries, compatibility negotiation, usage accounting, and native tool
  validation make provider failures and reported usage clearer. Independent
  workspace reads can run together while writes and commands remain ordered.
- **New chats handle storage failures better.** A chat can remain usable as a
  preview if its first session write fails; its first successful send promotes
  it to a persisted session. Failed creation no longer leaves an incomplete
  session record.
- **The download site has refreshed product visuals** for chat, review, and
  workspace screens.

## Behavior changes and known limits

- This Alpha remains ad-hoc signed and is not Apple-signed or notarized.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. Keep app and CLI versions aligned when handing sessions between them.
- Provider usage may include previously omitted tool rounds or retries. Estimates
  are not hard spend ceilings. Performance improvements have not been established
  with comparable live-provider trials.

## Upgrade and rollback

Update from Gyro, or replace the application with the matching Alpha 49.7 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.6`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.6).
Keep the backup until you have verified your sessions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.7/gyro-cli-0.1.0-alpha.49.7-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.7/gyro-cli-0.1.0-alpha.49.7-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
