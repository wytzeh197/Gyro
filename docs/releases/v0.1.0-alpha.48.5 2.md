# Gyro v0.1.0-alpha.48.5

Gyro Alpha 48.5 makes chat-owned browsing, durable working artifacts, and
long-running chat continuity more dependable. It also improves the accuracy of
context and local-model usage reporting without reducing tool or model access.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.5/Gyro_0.1.0-alpha.48.5_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.5/Gyro_0.1.0-alpha.48.5_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.5/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Each chat owns its browser page. Models with browser tools can observe a page,
  interact through current element references, and verify the result; supplied
  browser attachments remain immutable context.
- Canvas artifacts give chat a durable adjacent surface for documents, code,
  tables, and diagrams. Browser remains the surface for interactive apps.
- Provider stream handling preserves context-usage checkpoints and settles
  activities after interrupted or out-of-order streams.
- Complete Ollama tool-round measurements reach the usage ledger; incomplete
  readings remain estimated instead of being presented as measured.
- Provider handoffs select conversation messages before applying the existing
  message and character bounds, so intervening tool activity no longer crowds
  out the conversation.
- Plan turns retain their active goal, and the shared browser guide is included
  once rather than duplicated in affected provider prompts.

## Behavior changes and known limits

- Browser evidence is current only when it is observed in the live browser;
  an attachment does not update after a page changes.
- Context and ledger estimates still cannot include provider-hidden instructions,
  attachments, or tool cycles when a provider does not report them.
- Automated checks cover the browser, canvas, stream, usage, and continuity
  contracts. Native visual acceptance and updater behavior require the release
  artifacts on their target hardware.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.5 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.4`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.4).
This release does not introduce a session schema migration.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.5/gyro-cli-0.1.0-alpha.48.5-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.5/gyro-cli-0.1.0-alpha.48.5-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
