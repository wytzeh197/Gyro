# Gyro v0.1.0-alpha.49.5

Gyro Alpha 49.5 strengthens Workspace tools, local-model tool use, and scheduled
work. It also improves split chats, questions, attachments, and review flows.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.5/Gyro_0.1.0-alpha.49.5_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.5/Gyro_0.1.0-alpha.49.5_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.5/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Workspace roots are part of each session.** A chat can keep multiple
  selected folders, and tool calls identify the root they use. Removing a root
  blocks pending edits against it. Changes to the root set invalidate an active
  tool run so it cannot silently act against an outdated Workspace.
- **Live editor text has an explicit approval.** The model can request the
  current editor buffer or selection through a separate tool. The review shows
  the requested text, grants it for one call, and rejects the read if the text
  changes while approval is pending. File edits can use the returned document
  version to reject a stale edit.
- **Local models gain a bounded tool path.** Ollama models without native tool
  calls can discover Gyro's tool schemas and make structured requests through
  the same capability policy. OpenAI-compatible models also gain this fallback.
  Malformed requests get one retry; tool rounds remain bounded.
- **Scheduled work is more reliable.** Automation runs retain receipts, recover
  interrupted leases, and preserve pause and completion state across restart.
  The Automations screen supports creating, editing, running, and filtering
  schedules, including calendar times and stop conditions.
- **Chat workflows are clearer.** Questions appear in the composer with
  keyboard choices. New sessions in split view keep distinct panes. Each draft
  keeps its own mode and model choice until sent. Dropped images reach the pane
  under the pointer, and duplicate clipboard images collapse to one attachment.
- **Review and context are steadier.** Provider context and stream ordering have
  additional recovery checks, while file review, branch selection, and the
  companion dock keep their state through navigation.

## Behavior changes and known limits

- This release adds an additive session database column for Workspace identity.
  Older Gyro versions cannot use a multi-root session's extra folders. Back up
  the data directory before upgrading or rolling back.
- Live editor text requires a fresh approval even when Full access is enabled.
- Compatibility tool use depends on the local model producing valid structured
  JSON. A model that repeatedly returns invalid actions ends the turn with an
  error rather than executing an ambiguous request.
- Model Council remains unavailable while it is frozen.
- This Alpha is ad-hoc signed and is not Apple-signed or notarized.
- Use matching app and CLI versions for session handoff.

## Upgrade and rollback

Update from Gyro, or replace the application with the matching Alpha 49.5 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.4`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.4).
Keep the backup until you have verified your sessions. An older app will not
understand additional Workspace roots saved by this version.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.5/gyro-cli-0.1.0-alpha.49.5-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.5/gyro-cli-0.1.0-alpha.49.5-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
