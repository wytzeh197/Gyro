# Gyro v0.1.1

Gyro 0.1.1 improves project grouping and branch discovery, makes queued chat
delivery and provider recovery more reliable, and hardens browser interactions
and companion panel sizing.

## Candidate status

This document describes the intended v0.1.1 build. Publication and signed-package
acceptance are still required before these downloads exist.

## What changed

- Project sessions stay grouped by project, and branch pickers expose recent
  branch activity to make active work easier to find.
- Chat delivery distinguishes a saved turn from an instruction that never
  started. Queued messages retain their state without replaying saved failures.
- Provider recovery preserves quota categories and gives guidance for the
  selected provider. The built-in Codex connection keeps its OpenAI provider
  selection and does not inject a saved API key into the subscription CLI.
- Browser work improves document reference ownership, navigation and event
  routing, form interaction errors, and companion panel sizing on first reveal.
- Menu bar status and per-chat provider/model identity are clearer. Capability
  activity stays with the turn that produced it.

These changes do not establish a model speed or task-success comparison.

## Download and install

Requires macOS 14+ on Apple Silicon or Intel. Public stable artifacts must be
Developer ID signed and notarized by Apple. Local ad-hoc development builds do
not establish public signing or notarization acceptance.

After publication, use [the download site](https://usegyro.io/) or the exact
architecture download:

- [Apple Silicon: Gyro_0.1.1_aarch64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.1/Gyro_0.1.1_aarch64.dmg)
- [Intel: Gyro_0.1.1_x64.dmg](https://github.com/wytzeh197/Gyro/releases/download/v0.1.1/Gyro_0.1.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.1/SHA256SUMS)

Match the checksum to the exact filename you downloaded. Follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md)
(`docs/install-macos.md`).

## Behavior and known limits

Local work and user-owned provider connections remain available without a Gyro
account. Account, Plan & billing, and Cloud remain coming-soon settings; this
release does not enable hosted sign-in, purchases, uploads, sharing, or managed
AI. Provider usage reports may differ from a provider's current quota decision.

Browser checks on this development Mac do not establish Retina, older WebKit,
or Intel hardware acceptance. Both architecture packages and the signed updater
must pass release acceptance before publication.

## Upgrade and rollback

Quit Gyro and back up `~/Library/Application Support/Gyro/` before upgrading or
rolling back. After publication, install the matching DMG or use the signed
in-app updater. Version 0.1.1 is newer than the 0.1.0 launch build, so it can be
offered as an update once published. Verify that sessions and provider settings
survive the update before removing the backup.

To roll back, quit Gyro and manually reinstall the matching
[0.1.0 launch build](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-launch.20261106).
The updater does not perform downgrades. Restore the backup if the older build
cannot read data written by the newer build; cross-version downgrade acceptance
has not been established for this candidate.

## CLI

Keep app and CLI versions aligned when handing sessions between them. After
publication, the release includes:

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.1/gyro-cli-0.1.1-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.1/gyro-cli-0.1.1-x86_64-apple-darwin.tar.gz)

Each archive has a `.sha256` sidecar. The release also includes the generated
`gyro.rb` Formula. After the validated Formula reaches the tap:

```sh
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only.
