# Gyro v0.1.0-alpha.30.3

Gyro Alpha 30.3 is a chat and sidebar readability fix. Capability calls report
once instead of three times, they appear inside the turn that ran them rather
than above the whole conversation, and the project sidebar no longer spreads its
rows down the full height of the window.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.3/Gyro_0.1.0-alpha.30.3_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.3/Gyro_0.1.0-alpha.30.3_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.3/SHA256SUMS)

## What changed

- **A capability call reports once.** A single workspace read, terminal command,
  or browser open announces itself as it runs — requested, then running, then
  completed — and each report used to render its own card. One read stacked
  three near-identical rows. The call now keeps one card and updates it in
  place, the way an approval already did.
- **Capability calls appear where they happened.** They previously fell through
  to the transcript's loose events, which render ahead of every turn, so the
  workspace reads a turn performed showed up at the top of the conversation,
  above the message that asked for them. They now sit in the turn's own
  timeline, in the order they ran.
- A finished call reads **Done** rather than a lowercase `completed` beside a
  running call's **Working**.
- **The project sidebar packs its rows to the top.** The list stretches to fill
  the sidebar, and its grid handed that leftover height to the rows themselves —
  so with only a project or two, "Projects" and the first project could sit most
  of a screen apart, with the sessions under it spread just as far. Spacing is
  now the same whatever the list length.

## Behavior changes and known limits

- Collapsing a capability call to one card changes only how a run is displayed.
  The underlying events are unchanged, and existing transcripts re-render under
  the new grouping without migration.
- A capability call that carries no turn association still renders above the
  turns, as it did before. It is now a single card rather than one per status.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 30.2 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 30.2 data remains compatible with Alpha 30.3. Update from Gyro or replace
the existing application with the matching Alpha 30.3 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.30.2`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.30.2).

## CLI

The CLI is unchanged in this release and remains version-aligned with the app.
After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.3/gyro-cli-0.1.0-alpha.30.3-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.3/gyro-cli-0.1.0-alpha.30.3-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
