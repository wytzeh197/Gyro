# Gyro v0.1.0-alpha.47.6

Gyro Alpha 47.6 applies the chat and composer design, polishes branch creation,
and ships a calmer download site that defaults to light.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.6/Gyro_0.1.0-alpha.47.6_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.6/Gyro_0.1.0-alpha.47.6_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.6/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Chat and composer follow the approved Gyro design: one readable column, a
  quieter transcript, and a composer that sits in the same surface as the
  thread.
- Sidebar restore, back/forward, and thread controls share a consistent 16px
  window-action size.
- The new-branch dialog shows the start point as code and uses the same
  primary and secondary buttons as the rest of the app.
- usegyro.io defaults to light, drops the hero subtitle, and uses refreshed
  product media plus the launch film.
- Local execution timing is recorded for diagnostics. It does not change
  provider run policy or add a new user-facing timing panel.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- A stored dark site theme is still honored; first-time visitors see light.
- Execution timing is opt-in diagnostic data. It is not a public performance
  score and does not alter retries, timeouts, or approval flow.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.6 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.5`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.5).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.6/gyro-cli-0.1.0-alpha.47.6-aarch64-apple-darwin.tar.gz)
and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.6/gyro-cli-0.1.0-alpha.47.6-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
