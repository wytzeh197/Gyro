# Gyro v0.1.0-alpha.47.4

Gyro Alpha 47.4 makes provider workspace reads more dependable, hardens Kimi
ACP completion handling, and gives editor tabs a calmer action surface.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.4/Gyro_0.1.0-alpha.47.4_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.4/Gyro_0.1.0-alpha.47.4_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.4/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Provider workspace reads now honor requested line and column ranges beyond
  the editor preview, redact content before it leaves the app, and provide a
  continuation position when a result reaches the tool-response limit.
- Kimi ACP now handles bidirectional request-ID collisions correctly and fails
  malformed prompt completions instead of reporting a false successful turn.
- Editor tabs have a compact split menu and right-click file actions for save,
  revert unsaved changes, and close.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Workspace range reads are capped at 2,000 ordered lines and use the existing
  workspace scan limit for files that are not open in the editor.
- Kimi ACP still requires a working Kimi CLI session and its normal approval
  flow.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47.4 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.47.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.47.3).

## CLI

The CLI remains version-aligned with the app. Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.4/gyro-cli-0.1.0-alpha.47.4-aarch64-apple-darwin.tar.gz)
and [Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47.4/gyro-cli-0.1.0-alpha.47.4-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
