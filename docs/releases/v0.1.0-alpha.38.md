# Gyro v0.1.0-alpha.38

Gyro Alpha 38 keeps chat runs live until the provider process is actually done,
stops empty-margin clicks from cancelling a turn, and makes Stop vs Failed
readable on the run rail.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.38/Gyro_0.1.0-alpha.38_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.38/Gyro_0.1.0-alpha.38_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.38/SHA256SUMS)

## What changed

- **Runs stay live while the provider is still working.** Quiet tools no longer
  end a turn after thirty minutes of silence. Chat CLIs ignore stdout inactivity,
  Codex app-server no longer kills on protocol silence alone, and ACP providers
  (Grok, Kimi, Gemini) use the full 24-hour max runtime instead of a 30-minute
  wall clock. ACP also emits the same quiet-period heartbeats as Claude and
  Codex so the rail keeps saying Working.
- **Empty-margin clicks no longer stop the model.** Focusing an already-active
  chat pane is a no-op, stop requires a press that started on the Stop control,
  and composer/transcript gutters size from the pane (not the window) so side
  margins are not a huge accidental target.
- **Stop vs Failed is honest.** User cancel reads as **Stopped** with calm
  problem chrome; a real failure reads as **Failed** with danger tone. While the
  send is still open, a stale cancelled/failed status cannot paint Stopped over
  a live turn.
- **Calmer live chrome.** Stop uses a distinct quiet pill, live runs mark the
  shell as working, the composer shows a subtle sending edge, and reduced-motion
  users get a static live cue instead of breathing icons.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 37 sessions remain compatible; no destructive data migration
  is required.
- Chat provider runs still end on process exit, user Stop, or the 24-hour max
  runtime. Automations and non-chat commands keep their own shorter timeouts.
- Heartbeats keep the UI honest during quiet work; they do not replace a real
  completed or cancelled status when the process ends.
- Token ceilings and usage-guard pauses are unchanged.

## Upgrade and rollback

Alpha 37 data remains compatible with Alpha 38. Update from Gyro or replace
the application with the matching Alpha 38 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.37`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.37).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.38/gyro-cli-0.1.0-alpha.38-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.38/gyro-cli-0.1.0-alpha.38-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
