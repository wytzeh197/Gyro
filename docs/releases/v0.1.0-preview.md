# Gyro v0.1.0-preview

Gyro 0.1.0-preview is a signed build of the current v0.1.0 app. Chat can see
every open project file, including unsaved text in dirty editors, and the app
opens with Apple's normal downloaded-app prompt.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. This preview is signed with
Gyro's Developer ID and notarized by Apple. It opens after the standard
"downloaded from the internet" prompt.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview/Gyro_0.1.0-preview_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview/Gyro_0.1.0-preview_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

Replacing an older ad-hoc Alpha with this Developer ID build asks for
Accessibility again, and macOS may prompt once for the Keychain item that
holds a saved provider key. Choose Always Allow if that prompt appears.

## What changed

- **Chat can read the open workspace.** The capability bridge lists every open
  project tab. It holds the active editor, the selection, and other dirty
  files when that text fits. Reading live editor text still asks for approval
  once per disclosure. Saved files that are not held are read from disk.
- **This build is the current v0.1.0 app.** It includes the workspace, chat,
  provider, and appearance work on that branch since Alpha 49.7, including
  Grok Fast, Antigravity, goals, the browser tools, and source control.
- **The app is notarized.** Direct installs no longer use the Open Anyway step
  required by ad-hoc Alphas.

## Behavior changes and known limits

- This preview does not replace the Alpha update channel. Install it from the
  DMG links above. Automatic updates continue to follow the latest non-preview
  release until a stable v0.1.0 is published.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. Keep app and CLI versions aligned when handing sessions between them.
- A dirty editor whose text does not fit in the evidence budget must be saved,
  or read through a smaller selection, before chat can disclose it.

## Upgrade and rollback

Install the matching 0.1.0-preview DMG. Before changing versions, quit Gyro and
back up `~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.7`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.7).
Keep the backup until you have verified your sessions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview/gyro-cli-0.1.0-preview-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview/gyro-cli-0.1.0-preview-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key. App bundles and DMGs are signed with Gyro's Developer ID and notarized by
Apple.
