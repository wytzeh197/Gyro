# Gyro v0.1.0-alpha.30.2

Gyro Alpha 30.2 changes what the app does while a model works. The model now
reports where it is working instead of steering your window, the context meter
measures what a turn actually spends, and the website has been rebuilt.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.2/Gyro_0.1.0-alpha.30.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.2/Gyro_0.1.0-alpha.30.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.2/SHA256SUMS)

## What changed

- **The model shows where it is working without taking the window.** As tool
  calls report a file, terminal, browser, or output channel, Gyro records that
  focus and surfaces it as an ambient strip you can peek into inline. The
  editor, panel, and chat you were reading stay where you left them.
- A focus peek shows the revealed line in context and offers **Open in
  workspace** when you do want to go there, so following the model is a choice
  rather than the default.
- The new **model follow** preference keeps all three behaviors available:
  `off` for badges only, `peek` for the inline strip, and `follow` for the
  previous behavior where the app navigated along with the model. New installs
  default to `peek`.
- **The context meter measures a turn instead of estimating it.** For Claude
  Code, Gyro reads the run's own `stream-json` totals — the fresh input plus
  both cache buckets, against the context window the result frame attributes to
  the model that ran. A long conversation no longer reads as a few hundred
  tokens.
- **Plan limits are read from the provider that reports them.** Claude Code
  announces its window and reset time on the chat stream, and Gyro records it
  alongside the usage Codex reports on request.
- A usage window a provider never measures now renders as a named window with
  its reset time and no bar, instead of a fill that would have been invented.
- Global search ranks its results, so an exact name outranks an incidental
  substring match somewhere else in the workspace.
- A chat turn separates the work it did from the answer it ended with, while
  narration spoken before a tool call stays in place instead of being pulled to
  the end.
- **Provider CLIs installed in your home directory are found again.** A Gyro
  launched from the Dock inherits a minimal system PATH, so a Kimi, Grok,
  Cursor, or npm-global install could be reported as missing immediately after
  a successful terminal login. PATH resolution is now shared by the app,
  health checks, GitHub, and the ACP agents, and it covers those locations.
- Provider sign-in finishes the same way for every provider: the login command
  exiting successfully completes it, and Gyro returns you to the providers
  surface. A forced repair still refuses to accept a status command's word for
  it, because that is the claim that proved unreliable in Alpha 30.1.
- **The website has been rebuilt** with new product captures, a light and dark
  theme toggle, and a mobile layout that no longer crowds its headings.

## Behavior changes and known limits

- `peek` is the default for every install, including upgrades. If you preferred
  the app switching along with the model, set **Model activity** back to
  **Follow** under Settings › General › Model activity.
- Measured token usage currently covers Claude Code and Codex. The ACP agents
  (Kimi, Gemini, Grok) publish no usage, so the composer keeps its own estimate
  for them and reports no plan limits.
- Claude Code names a plan window and its reset but never how full it is. Only
  an exhausted window resolves to a level, and that one is measured rather than
  guessed — an in-progress Claude Code window intentionally shows no bar.
- A model focus is descriptive only. It never changes the active destination,
  workspace layout, or tool panel by itself.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 30.1 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 30.1 data remains compatible with Alpha 30.2. Update from Gyro or replace
the existing application with the matching Alpha 30.2 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.30.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.30.1).

## CLI

The CLI is unchanged in this release and remains version-aligned with the app.
After the release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.2/gyro-cli-0.1.0-alpha.30.2-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30.2/gyro-cli-0.1.0-alpha.30.2-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
