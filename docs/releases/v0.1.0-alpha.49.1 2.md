# Gyro v0.1.0-alpha.49.1

Gyro Alpha 49.1 improves how models inspect and change a workspace, makes
provider and workspace connections more reliable, and fixes desktop layout,
startup, and download-site failures.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.1/Gyro_0.1.0-alpha.49.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.1/Gyro_0.1.0-alpha.49.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.1/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Models can inspect larger projects without losing results.** Code
  definitions, references, file symbols, and Git history support continued
  reading through bounded pages. Deeply nested symbols remain reachable, and
  code positions stay accurate on lines containing emoji. Git blame handles
  single-line files without a trailing newline and reports how to continue.
- **Workspace connections fail clearly and recover more reliably.** The model
  bridge validates connections, bounds protocol messages, reports tool errors,
  and preserves the outcome of reviewed file changes. Workspace preparation
  and file observations remain aligned with the active chat.
- **Incomplete provider output cannot dispatch its tool calls.**
  OpenAI-compatible and Ollama responses stopped by an output limit report an
  error. Provider errors and malformed streams no longer look like successful
  tool plans. Thinking-state replay and streamed tool reconstruction improve
  compatibility with supported API providers.
- **Model selection can receive compatible catalog updates.** The app can load
  a versioned model catalog, retain a validated offline cache, and handle
  rollout or rollback without removing bundled models. New native providers
  still require an app update. The xAI default model is Grok 4.7.
- **The desktop is more resilient at startup and in compact layouts.** Startup
  and rendering failures expose recovery controls; background polling pauses
  when it is not useful. Chat close controls target the correct pane. Settings
  navigation and provider rows remain reachable in narrow windows, and shell
  and conversation styling are more consistent.
- **Downloads remain usable when optional information fails.** The site no
  longer waits for architecture detection before loading downloads, preserves
  manual selections, validates asset links, and clears stale checksums.

## Behavior changes and known limits

- Code navigation requires an installed, supported language server. An
  indexing response is a request to retry, not proof that no symbols exist.
  Positions whose source cannot be read are explicitly unavailable.
- Navigation and history pages reflect current state. Restart a query when
  files change; use a commit hash for a stable Git history query.
- A failed provider response does not roll back tool rounds that already
  completed. Review the reported workspace state before retrying.
- Use matching app and CLI versions for session handoff. Restart a stale app
  when the CLI reports an incompatible running instance.
- Remote model entries must be compatible with an existing integration;
  catalog updates cannot install a provider or grant additional permissions.
- Existing command, file-edit, workspace, and browser approval policies remain
  in force. This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 49.1 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49).
This release does not add a session database schema migration. Keep the backup
until you have verified your sessions in the version you intend to use.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.1/gyro-cli-0.1.0-alpha.49.1-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.1/gyro-cli-0.1.0-alpha.49.1-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
