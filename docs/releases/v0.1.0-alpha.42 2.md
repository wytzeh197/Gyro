# Gyro v0.1.0-alpha.42

Gyro Alpha 42 is a focused reliability release for the final Alpha cycle. It
makes the desktop workbench clearer about system appearance and local-model
readiness, while keeping an older saved workspace from breaking a new chat.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.42/Gyro_0.1.0-alpha.42_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.42/Gyro_0.1.0-alpha.42_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.42/SHA256SUMS)

## What changed

- **System appearance now follows macOS consistently.** The workbench,
  terminal, and editor resolve the same Dark or Light appearance when System
  is selected, including after relaunch.
- **Ollama tells you exactly what is missing.** If Ollama is running but has no
  local models, Gyro blocks the composer, explains that a model needs to be
  pulled, and leads to the provider settings where the connection can be
  tested.
- **Older saved workspaces fail safely.** A malformed historical terminal line
  can no longer make the chat workbench crash while assembling workspace
  context; invalid entries are skipped instead.
- **Release checks gained coverage for these paths.** The workbench smoke test
  now covers System appearance, an empty Ollama model list, the repair route to
  provider settings, and stale saved-output data.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Ollama remains a local, loopback-only provider. Gyro cannot install models on
  your behalf; use `ollama pull <model>` and then test the provider in Gyro.
- A provider chat still requires a configured account or locally installed
  model. This release does not send a chat during setup or health checks.

## Upgrade and rollback

Alpha 41 data remains compatible with Alpha 42. Update from Gyro or replace
the application with the matching Alpha 42 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.41`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.41).
Existing local sessions remain available after the rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.42/gyro-cli-0.1.0-alpha.42-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.42/gyro-cli-0.1.0-alpha.42-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
