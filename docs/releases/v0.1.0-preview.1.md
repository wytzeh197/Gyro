# Gyro v0.1.0-preview.1

Gyro 0.1.0-preview.1 is the next signed build of the v0.1.0 app. Explorer can
move, duplicate, and undo files, Ask Gyro can attach a project file, and file
tabs stay compact. It opens with Apple's normal downloaded-app prompt.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. This preview is signed with
Gyro's Developer ID and notarized by Apple. It opens after the standard
"downloaded from the internet" prompt.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.1/Gyro_0.1.0-preview.1_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.1/Gyro_0.1.0-preview.1_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.1/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

Moving from an ad-hoc Alpha to this Developer ID build asks for Accessibility
again. Moving from v0.1.0-preview keeps the same signing identity. macOS may
prompt once for an older Keychain item that holds a saved provider key. Choose
Always Allow if that prompt appears. New keys are saved on this Mac.

## What changed

- **Explorer can change paths.** Create a file or folder in the row, drag an
  entry onto a folder, or use Move… and Duplicate. Undo and Redo put the path
  change back. A chat path card shows Undo while that change is still the
  latest one.
- **Ask Gyro attaches a project file or folder.** The composer takes focus
  after the attachment lands. Dropping a folder on the window opens it.
- **Copy and Reveal use the real file.** Copy Path, Copy Relative Path, and
  Reveal in Finder no longer point at the workspace root or a doubled path.
- **File tabs stay compact.** The sidebar band remains tall enough for the
  traffic lights. Editor tabs keep the compact row height.
- **Kimi K3.1 is in the catalog.** Kimi K3.1 Pro and Kimi K3.1 Highspeed can
  be selected. Resumed sessions are compacted, and an outside agent can
  continue one.
- **Automations have CLI controls.** `gyro automate list`, `run`, `pause`, and
  `resume` manage saved automations. Resume is refused unless the automation
  is paused.

## Behavior changes and known limits

- After this preview is published, the download site and the in-app updater
  follow it. It is the latest release. Install the DMG above if an older app
  does not offer the update yet.
- Back up `~/Library/Application Support/Gyro/` before upgrading or rolling
  back. Keep app and CLI versions aligned when handing sessions between them.
- A move stays inside the workspace folder it started in. A file with unsaved
  editor changes has to be saved or reverted before it can move.

## Upgrade and rollback

Install the matching 0.1.0-preview.1 DMG. Before changing versions, quit Gyro
and back up `~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-preview`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-preview).
Keep the backup until you have verified your sessions.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.1/gyro-cli-0.1.0-preview.1-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-preview.1/gyro-cli-0.1.0-preview.1-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key. App bundles and DMGs are signed with Gyro's Developer ID and notarized by
Apple.
