# Gyro v0.1.0-alpha.34.4

Gyro Alpha 34.4 improves provider plan usage (including real xAI weekly
credit), cleans Settings so only provider-reported windows appear, and
polishes the in-chat browser and run rail.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.4/Gyro_0.1.0-alpha.34.4_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.4/Gyro_0.1.0-alpha.34.4_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.4/SHA256SUMS)

## What changed

- **Real provider plan windows.** Usage Limits shows only windows the provider
  actually reports (for example Codex 5h/weekly, Claude session/weekly, xAI
  weekly credit). Percentages are **used/spent**, filling as allowance is
  consumed—not invented “available” cards for every model.
- **xAI weekly credit.** Gyro reads Grok ACP billing (`_x.ai/billing`) so the
  weekly plan bar matches credit usage from the account, not a local estimate.
- **Bars / wheels** apply to those provider plan cards.
- **Measured by Gyro removed** from Settings → Usage Limits. Local ledger
  still powers spend limits and pause; it is no longer shown as competing
  progress bars.
- **In-chat browser.** Resize from the left edge while docked on the right;
  rail and drag polish from the prior workstream.
- **Run rail.** Plan lines stay under the work header; clearer tool rows and
  fewer orphan stream fragments (carried from 34.3 polish).

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- Existing Alpha 34.x sessions remain compatible.
- Providers without a plan-usage API still show empty or error state for
  allowance cards; daily token budgets remain available under Spend limits.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 34.4 DMG.
To roll back, reinstall
[`v0.1.0-alpha.34.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.34.3).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.4/gyro-cli-0.1.0-alpha.34.4-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.34.4/gyro-cli-0.1.0-alpha.34.4-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
