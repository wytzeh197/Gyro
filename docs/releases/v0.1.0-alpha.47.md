# Gyro v0.1.0-alpha.47

Gyro Alpha 47 improves browser-assisted work, makes completed chats easier to
spot, and refines side chat and inline change review.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47/Gyro_0.1.0-alpha.47_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47/Gyro_0.1.0-alpha.47_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Bring the browser into your chat.** Attach a captured page with its URL,
  page text, and a screenshot when supported. Browser use also works in chats
  without a project folder.
- **Better model browser guidance.** Models receive clearer browser tool and
  observation context, including whether they can actually see an image.
- **Spot finished work.** Background chats show an unread completion indicator
  until you open them.
- **Smoother chat and review.** Refined side chat, reasoning-effort controls,
  inline change review, and command filtering. Fresh chats start with a fresh
  side panel.
- **Experimental provider options.** Added opt-in Cursor and OpenCode CLI
  adapters with streaming, resume, cancellation, and permission callbacks.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- A provider chat requires a configured account or locally installed model.
- Cursor and OpenCode are disabled by default and have not been verified with
  real provider accounts. They use the CLI's configured model; image input and
  usage reporting are not supported. Cursor question and plan extensions are
  cancelled rather than answered in chat. OpenCode custom agent permissions
  can override global settings; approval enforcement remains experimental.
- Browser snapshots describe the captured page, not subsequent navigation.
  Screenshot delivery depends on the selected provider's image support.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 47 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.46`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.46).

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47/gyro-cli-0.1.0-alpha.47-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.47/gyro-cli-0.1.0-alpha.47-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
