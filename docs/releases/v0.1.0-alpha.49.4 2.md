# Gyro v0.1.0-alpha.49.4

Gyro Alpha 49.4 is a reliability release. It ends stalled provider runs instead of
waiting on them forever, keeps partial answers rather than replaying them, stops
retries the moment you press Stop, and keeps plan-usage meters live during a turn.
The native runner now keeps its own copy of the remote model catalog, so ordinary
new models, starting with **GPT-6 Sol** and **GPT-6 Luna**, need no app release. It
includes no session database migration.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.4/Gyro_0.1.0-alpha.49.4_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.4/Gyro_0.1.0-alpha.49.4_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.4/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **A silent provider no longer holds a chat forever.** After five minutes with
  no output, the activity line says how long the provider has been silent. After
  30 minutes of silence the run ends as stalled and offers a recovery. A running
  tool or a pending approval never counts as silence.
- **Partial answers are kept, not replayed.** Once a turn has shown output, a
  transient failure no longer retries it from the start and duplicates the
  reply. An answer cut off by an early provider exit stays in the thread with
  **Continue**.
- **Stop is immediate during a retry.** The backoff between retries checks for
  Stop every 50 ms instead of finishing its wait first.
- **Plan usage stays current.** The backend pushes a fresh reading when a turn
  first reports a rate limit, and every window shares the latest poll. The meter
  footer shows how old a reading is and marks it once it is stale or the last
  refresh failed. Readings whose reset times differ by less than a minute now
  count as the same window, so a level no longer disappears. Claude plan usage
  also reads the newer `limits` format.
- **The runner follows the model catalog.** Codex and Grok take each model's
  allowed reasoning levels from the catalog, and the context meter takes its
  window from there too, before falling back to the bundled tables. The catalog
  is saved locally and survives a restart without a network. It is rewritten
  only when it changes. Catalog client revision 2 adds **GPT-6 Sol** and
  **GPT-6 Luna**.
- **Context windows match what the CLIs serve.** GPT-5.x models through Codex
  now use the 272K window Codex serves instead of 1.05M. Grok 4.5 uses 500K.
  Kimi uses 262,144. An empty thread no longer shows "0 of 1M".
- **Connections are sturdier.** Ollama and OpenAI-compatible providers reuse
  pooled connections and time out only after a period of inactivity: 30 minutes
  for Ollama, 10 for OpenAI-compatible providers. Long generations no longer hit
  a fixed overall deadline. Kimi sessions resume from the session they opened,
  and cancelling Kimi reads as a stop rather than an error. Codex temporary
  response files are removed on every exit path.
- **CLI updates are clearer.** An npm-installed provider CLI updates with the npm
  that owns it. Versions are compared semantically, and "already up to date"
  counts as success. A failed update names the CLIs that did not update.
- **Workspace polish.** Explorer lists project content first, then dotfile
  configuration, then dependency and build output. A dropped image attaches
  once, even with several chats open. App notices center over the conversation
  when a side panel is open. Reopening Terminal after Browser restores a usable
  editor height. The macOS traffic lights keep their inset through full-screen
  and resize.

## Behavior changes and known limits

- A provider that is genuinely silent for 30 minutes, with no running tool or
  pending approval, now ends as stalled. Continue from the recovery to resume it.
- The context meter for Codex-served GPT-5.x models fills sooner than before
  because it now measures against the 272K window Codex actually serves.
- Installs on earlier Alphas do not see GPT-6 Sol or GPT-6 Luna. Those entries
  require catalog client revision 2, which ships in this version.
- A model that needs new native handling, a new CLI flag or a new runner still
  needs a normal app release.
- Model Council remains unavailable while it is frozen.
- This Alpha is ad-hoc signed and is not Apple-signed or notarized.
- Use matching app and CLI versions for session handoff.

## Upgrade and rollback

Update from Gyro, or replace the application with the matching Alpha 49.4 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.49.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.49.3).
This release does not add a session database schema migration. Keep the backup
until you have verified your sessions in the version you intend to use.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.4/gyro-cli-0.1.0-alpha.49.4-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.49.4/gyro-cli-0.1.0-alpha.49.4-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
