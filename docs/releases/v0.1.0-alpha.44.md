# Gyro v0.1.0-alpha.44

Gyro Alpha 44 makes multi-chat work more dependable. Queued messages keep
moving in their original chat, even when you switch away, and long-running
workspace tasks stay available in the terminal where their output belongs.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.44/Gyro_0.1.0-alpha.44_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.44/Gyro_0.1.0-alpha.44_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.44/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **Queued messages continue in the right chat.** When a response finishes,
  the next message for that chat is delivered even if you have moved to a
  different conversation. Per-chat ordering and retry delays remain intact.
- **Workspace tasks handle real development workloads.** Dev servers and
  watchers run in interactive terminal panes, while build and test tasks can
  remain quiet for longer without being stopped as inactive.
- **A project folder is optional for conversation.** You can start a provider
  chat without a folder; file, diff, terminal, and workspace actions remain
  available only after you select a project.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- A provider chat still requires a configured account or locally installed
  model.
- Workspace actions require a user-selected project folder.

## Upgrade and rollback

Alpha 43 data remains compatible with Alpha 44. Update from Gyro or replace the
application with the matching Alpha 44 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.43`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.43).
Existing local sessions remain available after the rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.44/gyro-cli-0.1.0-alpha.44-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.44/gyro-cli-0.1.0-alpha.44-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
