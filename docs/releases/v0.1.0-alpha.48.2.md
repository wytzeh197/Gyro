# Gyro v0.1.0-alpha.48.2

Gyro Alpha 48.2 makes long-running agent work more dependable: chats can stay
alive while commands run, the activity rail reflects Codex reasoning, and the
composer handles larger screen recordings without blocking the UI.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.2/Gyro_0.1.0-alpha.48.2_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.2/Gyro_0.1.0-alpha.48.2_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.2/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- Chat sessions retain their active run state through long-running commands,
  with clearer wait, completion, and recovery behavior.
- The chat activity rail now shows concise Codex reasoning updates alongside
  tool and command progress.
- Resumed Codex turns avoid resending stable workspace and browser guidance,
  reducing repeated context without removing current approval policy.
- The composer accepts screen recordings up to 200 MB, transfers media as raw
  bytes to avoid webview stalls, and recognizes more QuickTime containers.
- Browser navigation and clean-machine behavior have dedicated regression
  coverage; chat, context-usage, and workbench views received visual and
  accessibility refinements.

## Behavior changes and known limits

- A chat run remains active while Gyro waits for a finite command; a wait that
  has not completed is not a failed command.
- Video attachments can use substantial local storage. Gyro limits a turn to
  512 MB and retains up to 1 GB of stored attachments per session.
- Provider connections, native permissions, clean-user installation, and
  updater behavior require desktop acceptance beyond automated regression
  tests.
- This Alpha remains ad-hoc signed and not notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.2 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.1`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.1).
This release does not introduce a session schema migration; older versions do
not include the improved run continuity or richer activity updates.

## CLI

The CLI remains version-aligned with the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.2/gyro-cli-0.1.0-alpha.48.2-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.2/gyro-cli-0.1.0-alpha.48.2-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
