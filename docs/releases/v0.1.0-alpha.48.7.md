# Gyro v0.1.0-alpha.48.7

Gyro Alpha 48.7 adds API-key providers. DeepSeek, Mistral, OpenRouter, and any
OpenAI-compatible endpoint you define can now run a chat inside Gyro over its own
HTTPS connection, with the same tools, approvals, and streamed activity as a
provider CLI. It also makes readiness checks and chat cost reporting steadier.

## Download and install

Gyro requires macOS 14+ on Apple Silicon or Intel. Alpha app bundles use ad-hoc
code signing and are not Apple-signed or notarized. First launch requires
Apple's one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to choose your build, then
follow the [macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.7/Gyro_0.1.0-alpha.48.7_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.7/Gyro_0.1.0-alpha.48.7_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.7/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **API-key providers.** DeepSeek, Mistral, and OpenRouter join the provider
  list, and you can add your own OpenAI-compatible endpoint in Settings with a
  base URL and key. These run over Gyro's own HTTPS client rather than a
  provider CLI, so they cross the same capability broker, approval policy,
  audit path, and stop control as every other provider.
- **Custom provider management.** Define, edit, enable, and remove your own
  endpoints in Settings, and manage the same entries from the CLI. The custom
  provider form can test the endpoint and list the models it advertises
  directly from the provider, so a definition matches what the server offers.
- **OpenRouter model list and effort.** OpenRouter carries current routed models
  and its own reasoning-effort ramp, so effort is offered only where the
  endpoint actually supports it.
- **Steadier provider readiness.** Readiness results are reused for a short
  window instead of starting a provider CLI on every check, including the
  repeated checks during sign-in. Pressing Connect, using **Test provider**, or
  finishing a sign-in always probes for real, and saving or removing a stored
  API key invalidates the previous result.
- **Visible running cost.** Providers that report per-request token counts now
  publish a running turn total as the turn works, instead of only once it
  finishes.
- **Faster launch.** Shell warm-up no longer blocks the first usable window on a
  whole-database integrity scan.
- Chat transcript attachments, provider stream ordering, and session browsing
  were hardened on the way to this release.

## Behavior changes and known limits

- An API-key provider bills the key you configure. Gyro stores it in the macOS
  Keychain when you save it there, and Gyro is the only client counting the
  tokens it sends; a provider's own dashboard remains the authority.
- Model lists for a custom endpoint reflect what the endpoint advertises when
  you fetch them. A renamed or retired model on the server side needs another
  fetch to disappear from the picker.
- A provider CLI sign-in still owns its own credentials. Choosing an API-key
  provider does not migrate or reuse a CLI login.
- Providers that do not report token counts keep showing estimated usage.
- This Alpha remains ad-hoc signed and not Apple-signed or notarized.

## Upgrade and rollback

Update from Gyro or replace the application with the matching Alpha 48.7 DMG.
Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.48.6`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.48.6).
This release adds optional configuration fields for custom providers and does not
introduce a session schema migration; an older build ignores providers it does
not recognize.

## CLI

The CLI remains version-aligned with the app, and can manage the same custom
providers as the app.

- [Apple Silicon CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.7/gyro-cli-0.1.0-alpha.48.7-aarch64-apple-darwin.tar.gz)
- [Intel CLI](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.48.7/gyro-cli-0.1.0-alpha.48.7-x86_64-apple-darwin.tar.gz)

After the validated Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
# Existing CLI installations:
brew upgrade wytzeh197/tap/gyro
```

Homebrew installs the CLI only. Updater archives are signed with Gyro's updater
key, independently of the application's ad-hoc macOS signature.
