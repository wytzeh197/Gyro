# Gyro v0.1.0-alpha.45

Gyro Alpha 45 is a maintenance release that keeps the desktop app, CLI,
updater, download artifacts, and Homebrew Formula on one release version. It
includes the dependable multi-chat and workspace behavior delivered in Alpha
44, without introducing a new workflow or changing stored session data.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.45/Gyro_0.1.0-alpha.45_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.45/Gyro_0.1.0-alpha.45_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.45/SHA256SUMS)

Match the checksum to the exact filename you downloaded before installing.

## What changed

- **One aligned release version.** The desktop app, CLI, updater metadata, and
  release tooling now identify this build as Alpha 45.
- **No workflow migration.** Conversations, selected projects, and existing
  local sessions remain compatible with Alpha 44.

## Behavior changes and known limits

- Alpha app bundles remain ad-hoc signed and not notarized.
- A provider chat still requires a configured account or locally installed
  model.
- Workspace actions require a user-selected project folder.

## Upgrade and rollback

Alpha 44 data remains compatible with Alpha 45. Update from Gyro or replace the
application with the matching Alpha 45 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.44`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.44).
Existing local sessions remain available after the rollback.

## CLI

The CLI remains version-aligned with the app. After the release Formula reaches
the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.45/gyro-cli-0.1.0-alpha.45-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.45/gyro-cli-0.1.0-alpha.45-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
