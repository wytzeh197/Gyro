# Gyro v0.1.0-alpha.30

Gyro Alpha 30 gives the CLI surface a reason to exist. A Claude Code pane opened
in Gyro now runs under Gyro's approval policy instead of behaving like any other
terminal window, and the CLI rail reports what is actually true about each pane.

## Download and install

Gyro requires macOS 14+ and is not Apple-signed or notarized. The application
uses a complete ad-hoc signature, so the first launch still requires Apple's
one-time **Open Anyway** approval.

Use the [Gyro download site](https://usegyro.io/) to select the correct build,
then follow the
[macOS installation guide](https://github.com/wytzeh197/Gyro/blob/main/docs/install-macos.md).
Do not disable Gatekeeper or remove quarantine globally.

- [Apple Silicon DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30/Gyro_0.1.0-alpha.30_aarch64.dmg)
- [Intel DMG](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30/Gyro_0.1.0-alpha.30_x64.dmg)
- [SHA256SUMS](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30/SHA256SUMS)

## What changed

- **Governed CLI panes.** A Claude Code pane launched with a workspace now runs
  under the same approval policy and capability bridge a Chat turn gets. Its
  file edits arrive as reviewable Gyro proposals with real diffs, decidable in
  Diff review or from `gyro approvals`, rather than a terminal prompt that
  scrolls out of the buffer.
- Each governed pane gets its own persisted CLI session, so pane work is
  discoverable from `gyro sessions` and survives a pane restart with its
  identity intact.
- The CLI rail no longer shows fixed placeholder text. Agent, branch, pane count
  and approval state are read from the selected pane, and the approval metric
  reports protection only when the backend confirms it.
- Provider argument contracts are audited before Gyro spawns a provider CLI, so
  an argument mismatch surfaces as a specific, actionable error instead of an
  opaque provider failure with a retry hint that could never succeed.
- New `gh`-backed GitHub integration reads repository state through the user's
  existing `gh` login. Gyro stores no GitHub token of its own, and degrades to a
  quiet empty state when `gh` is missing or logged out.
- Capability policy, session context, and the provider catalog gained supporting
  extensions for the above.

## Behavior changes and known limits

- Governance covers Claude Code only. Codex panes remain ungoverned because
  Codex approves through the app-server path, which a raw terminal pane cannot
  speak; those panes are labelled **terminal only** rather than implying
  protection they do not have.
- A pane opened without a workspace, or while Anthropic is disabled in settings,
  still opens — ungoverned, with a notification explaining why.
- Panes launched from a command override run through the shell and are never
  governed.
- GitHub features require the `gh` CLI to be installed and authenticated. Gyro
  does not install `gh` and never takes ownership of GitHub credentials.
- Gyro remains an unsigned public Alpha. Managed Macs may prohibit **Open
  Anyway**, and Gyro does not bypass device policy.
- Apple Silicon and Intel remain separate downloads; there is no universal DMG.
- Homebrew installs the `gyro` CLI only. Gyro.app remains a direct DMG install.
- Existing Alpha 29 sessions, projects, settings, and editor state remain
  compatible; no destructive data migration is required.

## Upgrade and rollback

Alpha 29 data remains compatible with Alpha 30. Update from Gyro or replace the
existing application with the matching Alpha 30 DMG.

Before changing versions, quit Gyro and back up
`~/Library/Application Support/Gyro/`. To roll back, reinstall
[`v0.1.0-alpha.29.3`](https://github.com/wytzeh197/Gyro/releases/tag/v0.1.0-alpha.29.3).

## CLI

Governed panes create ordinary Gyro sessions, so `gyro sessions`, `gyro resume`,
and `gyro approvals` all operate on pane work started in the app. After the
release Formula reaches the tap:

```bash
brew tap wytzeh197/tap
brew install wytzeh197/tap/gyro
```

Direct archives are available for
[Apple Silicon](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30/gyro-cli-0.1.0-alpha.30-aarch64-apple-darwin.tar.gz)
and
[Intel](https://github.com/wytzeh197/Gyro/releases/download/v0.1.0-alpha.30/gyro-cli-0.1.0-alpha.30-x86_64-apple-darwin.tar.gz).

## Alpha notice

This is a GitHub-built public macOS Alpha for Apple Silicon and Intel. Updater
archives are signed with Gyro's updater key, while application bundles use
ad-hoc code signing and DMGs are not Apple-signed or notarized.
