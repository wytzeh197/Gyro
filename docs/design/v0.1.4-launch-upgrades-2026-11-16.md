# v0.1.4 launch upgrades — 16 November 2026

Scope: implementation and verification on the existing v0.1.4 checkout.
The pre-existing remote, model-catalog, scroll, Usage and efficiency work was
preserved. Follow-up requests authorized reinstalling the complete local desktop
build and committing/pushing it to v0.1.4. The separate Cloud agents prototype
and email draft remain local. Cloud activation and a public release are outside
this delivery.

## Implemented

- Added the v0.1.4 branch to push CI. Connected all regression guards to runners
  and classified previously unregistered checks without excluding any guards.
  The launch browser group starts the preview server when needed and includes
  Environment, remote access, Usage, Problems, onboarding and the full Check suite.
- Replaced color/radius/font fallbacks with Gyro's existing semantic tokens.
  Preserved the tooltip's existing layer as a named token. No design or
  architecture budget was increased. Rust formatting was reconciled with CI.
- Bounded build/test output now supplies navigable Problems after the task
  finishes. Supports TypeScript locations, Rust diagnostic arrows, and common
  file:line[:column] compiler output. Paths must resolve to actual workspace
  files; external and escaping symlink targets are excluded. Results are
  deduplicated and capped at 500; unknown output remains available in Output.
- Task reruns clear only their own workspace's diagnostics. LSP publications
  update atomically and preserve task findings. Scoped IDE rendering excludes
  other workspaces. Repeated UI launches of the same in-flight task are ignored.
- Problems offers a keyboard-accessible Send to chat action. It attaches the
  diagnostic and opens chat without submitting a prompt or approving execution.
- The tour offers an optional first-task draft and retains Finish. It selects
  a project if needed, uses a fresh draft key, and asks for a proposed small
  change and verification before edits. Existing drafts remain untouched.
- Moved remote-root loading behind startup recovery so a failed import can
  display the same explicit retry screen as a failed main-app import.
- Replaced Check's missing historical mockup with the actual SubagentList and
  activity-summary implementation. Completed agent activity is not presented
  as independent verification. Updated stale structural checks to current
  handlers, status copy and tokens; JSX button checks now parse real attributes.
- Prepared v0.1.4 version surfaces, Cargo lock entries, Homebrew template and
  explicitly provisional release notes. Template URLs are not published assets.
