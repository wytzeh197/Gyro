# v0.1.2 interaction simplification

Wytze’s feedback: the new features took too long to understand at first glance.
This pass simplifies their entry points and initial setup while retaining Gyro’s
existing shell, tokens, provider choices and backend authority boundaries.

- Project memory is a labeled row beneath each expanded local project with a
  saved chat. It opens that project’s chat companion. The panel explains its job,
  offers **Add note**, and keeps note type/path options collapsed.
- **Get a second opinion** sits beside completed task changes and in Workspace
  review actions. Setup summarizes the project/change scope; reviewer/model are
  the initial choices. Root, scope and path filters remain editable in Options.
  **Preview review** captures locally; **Start review** is the explicit provider
  action. Preview replaces setup, with **Change setup** preserving selections and
  keyboard focus. History and preview cleanup are secondary disclosures.
- The existing Automations route is labeled **Workflows** in the sidebar. Chat
  tasks retain **Save as workflow**. Library copy uses create/edit/run wording;
  file locations and draft details are secondary. Run setup shows task details,
  models and checks; permission summaries remain visible, scheduling is optional,
  and the primary action advances from **Check setup** to **Start workflow**.
- Failed memory/reviewer loads offer retry and do not appear empty or loading.

Proposed design rule, recorded for review rather than added to shared instructions:
**Make the next action obvious; reveal extra choices when they become relevant.**
Reason: first use should explain the user’s task without requiring knowledge of
internal capture, binding or extraction terminology.
