GYRO FRONTEND POLISH — 15 OCTOBER 2026

Implemented locally on v0.1.0, retaining the existing work in progress.
The pass uses the current neutral surface palette, system typography, density
and interface-size controls, and user accent. Positioning means alignment and
placement within the existing app; product identity and navigation are retained.

CHANGES
- Chat: Send remains circular at all interface sizes. Removed composer/Send
  drop shadows. Split welcome screens no longer double their logo/composer
  margins, and their heading follows the shared heading size. Composer focus
  stays neutral.
- Settings: clickable rows have hover feedback, select controls align, and
  narrow text fields, color controls and keyboard bindings stack cleanly.
- Review: selectors and buttons share usable heights, labels wrap, and edit
  selectors have visible keyboard focus. Disabled actions do not highlight.
- Automations: long project paths and result actions wrap; primary text actions
  honor the user's accent; advanced options have clear disclosure feedback.
- Pull-request form: primary/secondary actions are distinct, Draft checkbox is
  inline, inputs and type use shared tokens, and short windows scroll to actions.
- Menus: Escape returns to the trigger that opened the current menu without a
  scroll jump. Leaving the menu dismisses it. Menu arrows no longer intercept
  unrelated focus, modified shortcuts or editable text.
- Confirmation dialogs: Tab stays inside the dialog, Escape cancels, and focus
  returns appropriately. Nested menus/controls receive Escape first. Native
  modal dialog behavior and reduced motion are retained.

LIMITS
This is browser rendering and interaction evidence using production React
components with simulated development data. It does not establish native
macOS WebView/window behavior, live providers, real GitHub actions, or installed
app acceptance. No macOS bundle was rebuilt or installed in this pass. Fixture
model names, dates, counts, terminals and repository operations are examples.
No full accessibility-compliance or exhaustive state-combination claim is made.

Existing dirty/untracked work was retained; no commit, push or publication was
performed. The prior packaged candidate does not include this new polish.
