# Gyro Cloud agents prototype

Local source only, disabled by default. No deployment, hosted migration,
provisioning, purchase, publication, or app integration is included.

Decision, API, lifecycle, setup boundaries and evidence:
[docs/cloud-agents.md](../../docs/cloud-agents.md).

```sh
cd services/cloud-agents
npm ci --ignore-scripts
npm run types
npm run typecheck
npm test
npm run test:runner
npm run test:database
npm run check:worker
npm run test:worker
```

`test:database` creates and destroys a separate local Postgres cluster. Set
`PG_BIN` to your Postgres binary directory; the default is Homebrew Postgres 17.
It never accepts a hosted connection string. `test:runner` exercises real local
Git with a deterministic fake agent, plus idle/deadline watchdogs. Linux user and
capability isolation is replaced only in that macOS-compatible test harness.

`check:bundle` additionally builds the Linux image and requires working Docker.
The local test suite does not establish that image or Cloudflare runtime works.
Worker types are generated, ignored files; regenerate after config changes.

The Supabase migration was generated by CLI 3.1.0. No hosted project is linked.
The existing `services/gyro-cloud` backup Worker and root package files are not
modified by this service.
