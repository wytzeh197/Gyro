# Typefaces

`inter-latin.woff2` is Inter, and `inter-tight-latin.woff2` is Inter Tight.
Both are the latin variable subsets as published by Google Fonts, vendored so
the desktop app loads no font CDN. Inter is designed by Rasmus Andersson and
distributed under the SIL Open Font License 1.1.
