Before you install

Common questions.

Ready for production work?

Not yet. Gyro can read files and run commands, so use it for alpha testing only.

See what shipped
Need a Gyro account or API key?

No. Sign in with your provider CLI; Ollama uses local models.

Need a CLI or local model first?

Yes. Install a supported CLI, or install Ollama and pull a model.

Read the install guide
Why does macOS warn me?

Alpha builds are not Apple-signed or notarized. Approve the first launch in System Settings; keep Gatekeeper on.

Read the install guide
Does Gyro replace the terminal?

No. It adds chat and review around real local shells.

What leaves my Mac?

Only what your provider needs to answer. App telemetry is off by default; this site has no analytics.
