Questions about Gyro.

What is Gyro?

Gyro is an open-source AI coding workspace for macOS, with agent chat, a local terminal, and code review in one app.

Explore chat, terminal, and code review
Is Gyro free to use?

Gyro is free under Apache-2.0. Bring a supported CLI or run Ollama locally. Cloud providers may charge for their services.

Read the Apache-2.0 license
Ready for production work?

Not yet. Gyro can read files and run commands. Use the alpha for testing.

See what shipped
What leaves my Mac?

Sessions and settings stay here. Cloud providers receive the task prompts and context; Ollama runs locally. Telemetry is off by default.

Privacy details
What do I need to get started?

macOS 14 or newer, plus a supported CLI or Ollama. No Gyro account required.
