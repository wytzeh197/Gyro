Before you install

Common questions.

Is it ready for production work?

Not yet. Install it only if you are comfortable testing software that can read files and run commands.

See what shipped
Do I need a Gyro account or API key?

No. Each agent CLI signs in through its own provider login on your Mac, and Gyro uses that session.

Do I need Claude, Codex, or another agent CLI first?

Yes. Install and sign in to at least one supported agent CLI yourself. Gyro does not install them.

Read the install guide
Why does macOS warn me on first launch?

Alpha builds are not Apple-signed or notarized, so macOS asks once in System Settings. Do not disable Gatekeeper.

Read the install guide
Does Gyro replace my terminal?

No. You get real PTY shells. Optional approval gates sit on top of the CLI you already run — Allow once, Always, or Deny.

What does it send off my machine?

Only what your provider CLI sends to answer a prompt. Gyro ships no telemetry, and this site loads no analytics.
